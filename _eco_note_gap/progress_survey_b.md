# 생태환경조사분석 노트 보강 — 에이전트 B (제9~15장) : 작업 완료

담당 범위 전체(제9장~제15장 + 부록 A~Q) 검토 종료. 총 **18개 지점** 보강.
`**관련 문제**:` 줄은 한 곳도 건드리지 않음(336줄 전수 보존 확인).

## 제9장 — 2절 수정
- 9.14.5 알베도: 백색도(whiteness) 어원, 0~1 무차원, 0=흑체/1=백체, 전파장 0.3~3.0μm, 분광알베도, **모든 태양각 반사율(≠단일입사각 reflectance)**, 태양각 낮을수록↑, 매끄러운 표면↑ (2020-3-73)
- 9.14.4: '인간이 인식하는 경관패턴 = 우점식생의 공간적 분포' (2020-3-67)
- 9.3 / 9.6 / 9.11 / 9.12 / 9.13 / 9.14.1~3 : 이미 정확 — 무수정

## 제10장 — 2절 수정
- 10.6.2: "토지개발에 따라 숲은 마멸·분화·천공화된다" 해설 원문 + 다섯 과정은 모두 축소 방향 (2020-3-76)
- 10.8: 개체군 큰 종이 안전한 이유(유전적 다양성 유지·근친교배 절멸위험 완화) (2020-3-78)

## 제11장 — 2절 수정
- 11.2.2: 해설의 이동통로 **5역할 목록**(통로/필터/서식지제공/종공급처/종수용처) 명시 + 필터 정의 원문. 노트의 6기능(장벽 포함)과 목록이 다른 점을 병기 (2020-3-80, 2021-2-73)
- 11.3.2: 하천 상/중/하류 대조표 — 차수(1~3 / 4~6 / 6차 초과), 경사(1:50 / 1:500 / 1:500), 에너지원(상류 유기물 **90% 이상** 부니질 의존), 섭식기능군, 유속 50cm/s·입자 5mm (2020-3-68)
- 11.4 : 이미 정확 — 무수정

## 제12장 — 1절 2항 수정
- 12.3.1 진행적 천이: 수직적 층화·안정 구조 서술 + 천이계열(sere) 구분 (2020-3-71)
- 12.3.2: 맥아더·윌슨·피앙카 **r/K 대조표**(적응전략·번식전략·사례) + "분류적·기능적으로 유사한 생물 비교 시 가장 유용" 단서 (2021-2-65)

## 제14장 — 3절 수정
- 14.2.1: **「도시생태현황지도의 작성방법에 관한 지침」** 4갈래 분류지표 표 전문 추가 + '대기의 질' 미등재 근거 (2022-1-19)
- 14.2.2: 같은 지침 표를 근거로 개체군 크기·외래종 서식현황 미등재 명시 (2022-1-2)
- 14.8.3: 도시 종수 제한의 실제 요인(파편화·오염·교란·열섬건조), '도시 서식종은 일반종이 대부분' 해설 문구, 지의류·선태류 감소에 **저습도** 원인 병기 (2020-3-65)
- 14.1 / 14.3(지도화 3방법 표) / 14.7 / 14.8.1~2 : 이미 정확 — 무수정

## 제15장 — 2절 수정
- 15.4.1: 우점종 정의를 **밀도·빈도·피도의 총체적 합**으로 정밀화, 핵심종·우산종·깃대종·희소종 정의를 해설 원문으로 교체, **여별종·침입종** 2개 항목 신규 추가, 깃대종 사례 5건(홍천 열목어·거제도 고란초·덕유산 반딧불이·태화강 각시붕어·광릉숲 크낙새) (2021-2-2)
- 15.7.2: **「생태·자연도 작성지침」 제6조** 평가항목 4개(식생·멸종위기야생생물·습지·지형)와 항목별 활용자료 표 추가 → 수질정화 배제 근거 확립 (2020-3-74)
