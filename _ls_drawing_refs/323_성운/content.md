## 문제지 — 2007년 2회 「근린공원설계」

시험시간 3시간 · 자격종목 조경기사 · 작품명 근린공원설계

**(1) 요구사항(제2과제)** — 다음은 중부지방에 위치한 주택지의 근린공원이다.

**(2) 부지 현황도** (S = 1/800) — 위 첫 장. 가로 80m, 서쪽 높이 60m · 동쪽 높이 105m 로 북쪽 경계가 비스듬한 사다리꼴입니다. 남쪽(주동선)에서 북쪽으로 등고선이 10에서 18까지 올라가는 경사지이고, 동쪽 경계에 부동선(아래)과 산책동선(위) 진입이, 남동 모서리에 배수맨홀이 있습니다.

### 문제 1 · 설계개념도

아래의 조건을 참고하여 현황도를 축척 1/300로 확대하여 설계개념도를 작성하시오. [도면 I]

- 가. 주동선과 부동선을 구분하고 산책동선을 설계할 것
- 나. 중앙광장, 운동공간, 전망 및 휴게공간, 놀이공간 등을 배치할 것
- 다. 도로에 차폐식재(완충녹지대)를 계획하고, 경관, 녹음, 요점, 유도 등 식재개념을 표기하시오

### 문제 2 · 시설물배치도

아래의 요구조건을 참고하여 축척 1/300로 확대하여 시설물배치도를 작성하시오. [도면 II]

- 가. 주동선은 남측 중앙(폭 9m), 부동선은 동측(폭 4m) 설계하며, 주민들이 산책할 수 있는 산책로(폭 2m)를 배치하고, 이들이 서로 순환할 수 있도록 설계할 것
- 나. 중앙광장 : 높이 +10.3, 폭은 15m로 조성, 수목보호대(1m × 1m) 설치할 것
- 다. 전망 및 휴게공간 : 높이 +14.5, 주동선(정면)과 같은 축선상에 위치
    - 중앙광장에서 계단, 램프(ramp)를 이용하여 접근할 수 있도록 설계할 것
    - 계단(단 높이 15cm, 단 너비 30cm), 램프(경사도 14% 미만)
    - 계단과 램프는 붙여서 그릴 것
- 라. 운동공간 : 다목적 운동공간(28m × 40m), 테니스 코트(24m × 11m), 배수시설 설치할 것
- 마. 놀이공간 : 시소(3연식), 그네(2연식), 미끄럼틀(활주판 2개), 철봉(4단), 정글짐, 회전무대 또는 조합놀이대 등 놀이시설 6개 배치, 배수시설 설치할 것
- 바. 퍼걸러(3m × 5m) 2개소, 벤치는 20개소, 음수대 1개소 설치할 것
- 사. 등고선은 점선으로 표기하고, 등고선 조작이 필요할 시 조작가능
- 아. 정지로 생긴 경사면 1:1로 조절할 것
- 자. 도면의 우측 여백에 시설물의 수량집계표를 작성할 것

### 문제 3 · 배식설계도

아래의 요구조건을 참고하여 축척 1/300으로 확대하여 배식설계도를 작성하시오. [도면 III]

- 가. 경사 구간은 관목을 군식할 것
- 나. 도로와 인접한 곳은 완충 녹지대를 3m 이상 조성할 것
- 다. 완충 녹지대는 상록 교목을 식재할 것
- 라. 각 공간의 기능과 경관을 고려하여, 지역조건에 맞는 수목 12수종 이상을 선정하되, 상록 : 낙엽의 비율이 3 : 7이 되도록 식재할 것
- 마. 도면의 우측 여백에 수목의 수량집계표를 작성할 것

- ③ 운동공간 — 공원이용자의 동적인 활동을 부여하고 안전성을 갖춘 공간으로 체력단련도 보장된다. 시설 : 배드민턴장, 평의자
- ④ 놀이공간 — 어린이를 위한 공간으로 신체적·정신적 단련의 기능을 갖는다. 시설 : 미끄럼대, 그네, 시소, 정글짐, 회전무대, 철봉
- ⑤ 경관식재 — 주변경관과의 연결성을 갖고 시각적으로 아름다운 수종을 자유형으로 식재한다. 식재 : 마가목, 철쭉, 잣나무, 홍단풍, 이팝나무, 진달래, 버즘나무, 층층나무
- ⑥ 차폐식재 — 인접 불량요소 차단을 목적으로 시각적 차폐가 가능한 상록수 식재로 시선차단과 방풍, 방음효과를 갖는다. 식재 : 독일가문비
- ⑦ 완충식재 — 각 공간의 구조적 프레임을 형성하여 기능적으로 공간이 분리되었음을 인식. 식재 : 은행나무
- ⑧ 유도식재 — 공원이용자의 동선을 결정하고 자연스러운 시선처리를 유도하여 안내자의 역할을 한다. 식재 : 버즘나무
- ⑨ 요점식재 — 시각적 유인성을 갖는 수형의 수목으로 경관성을 인식하게 한다. 식재 : 소나무
