세 장 모두 **도면 치수를 그대로 세운 입체 모형**에서 나온 그림입니다.
남동쪽 상공에서 북서쪽을 내려다본 시점이라 **도면의 북쪽이 그림의 위**입니다 —
실개천이 위, 기존수림이 왼쪽, 6m 도로와 주택가가 오른쪽·아래입니다.

# 실사 조감도를 만든 방법 (0 · 0b · 0c번 그림)

도면 치수를 그대로 넣은 3차원 모형을 남동쪽 상공에서 원근으로 본 그림(0b)을 GPT 에 주어
**재질만** 실사로 바꾸고, 사람 여섯을 넣고, 주변 경관을 이어 그리게 했습니다(0).

주변은 문제지 현황도 그대로입니다 — **위쪽에 실개천, 그 너머와 아래쪽에 야산(도시자연림),
왼쪽에 자연형 공원과 기존수림, 오른쪽과 오른쪽 아래에 6m 도로 건너 주택가**입니다.
(현황도의 방위표는 북쪽이 도면 왼쪽입니다.)

모형 이야기는 '입체평면도' 탭에 적어 두었습니다.

## 실사 7회차까지

배식설계도를 부지 좌표로 다시 읽어 식재를 고친 모형으로 다시 뽑았습니다. 참고 그림은
**늘 블렌더 조감도 원본**입니다 — 앞 회차 위에 덧그리면 회차마다 선명도가 깎입니다.

회차마다 고친 것:

| 회차 | 고친 것 |
| --- | --- |
| 1 | 첫 판 |
| 2 | 루프 안에 나무가 자랐다 → "습지 안은 초본류만, 교목·관목 금지" |
| 3 | 산림지구가 잔디로 나왔다 → 루프 바깥 전체를 수림으로 |
| 4 | 수목이 관찰로·조류관찰소를 덮었다 → "나무는 데크에서 물러선다" |
| 5 | **철새** · **버드나무 5** · **메타세쿼이아** 를 넣었다 |
| 6 | 동측 잔디가 나무로 꽉 찼다 → "정확히 열세 그루, 나머지는 잔디" |
| 7 | **도로에 차 다섯 대** — 달리는 셋 · 연석에 주차한 둘 |

- **철새** — 조류관찰소가 바라보는 저수지에 청둥오리 세 마리가 V자 물결을 남기며 헤엄치고
  백로 한 마리가 수면 위를 낮게 납니다. 크기를 "사람 머리만 하다"로 못박아야 백조만 하게
  그리지 않습니다
- **수종은 실루엣이 다른 것만 이름을 적습니다.** 은행나무(좁고 곧은 황록) · 버드나무(늘어진
  장막) · 메타세쿼이아(뾰족한 원뿔)는 이 높이에서도 구별됩니다. 갈참·졸참·상수리 세 참나무는
  수관이 다 둥글어 이름을 적어도 소용없습니다 — 이름을 늘릴수록 모델이 배치를 흔듭니다
- **차는 크기 기준을 주어야 합니다** — "위에서 지붕을 내려다본다, 차 길이는 **도로 폭보다
  조금 짧고 관찰데크 하나만 하다**". 안 그러면 버스만 하게 그립니다. 그림자 방향도 나머지와
  같아야 한다고 따로 적습니다
- **빈 잔디는 모델이 못 견디고 채웁니다.** "열려 있어야 한다 · 정확히 N그루 · 세어라
  하나, 둘, 셋…" 을 적어야 잡힙니다. 함께 철쭉 화단 설명을 "완만한 잔디 마운딩 위의 넓은
  화단" → "포장 가장자리의 폭 3m 짜리 좁은 띠"로 고쳤습니다 — 앞의 표현이 "여기는 채워도
  되는 넓은 땅"으로 읽힌 듯합니다
