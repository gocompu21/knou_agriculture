# 문항 그룹핑 기준 (자연생태복원기사 실기 필답)

같은 주제가 회차마다 되풀이 출제되므로, **묻는 것이 같은 문항끼리 묶는다.**
학습자가 "이 주제는 N회 나왔다"를 보고 우선순위를 정하고, 회차별로 어떻게
변형됐는지 나란히 대조하는 데 쓴다.

## 왜 사람이 직접 하는가

자동 군집화가 실패했다. `[box]` 지문을 버리고 발문만 보니
"다음 설명에 해당하는 용어를 쓰시오"라는 상투어만 남아,
**편향천이 · 저영향개발(LID) · 자기설계적 복원**이 한 그룹으로 묶였다.
전혀 다른 주제다. 99개 그룹 중 71개가 이런 오분류였다.

**답을 보면 같은 주제인지 1초 만에 알 수 있다.** 그래서 직접 읽는다.

## 판정 기준

### 같은 그룹으로 묶는다
- **답이 같은 개념**이면 묶는다. 표현이 달라도 상관없다.
  - `복원·복구·대체를 설명하시오` / `복원과 복구는 어떻게 다른가` / `생태복원의 유형 3가지`
    → 전부 같은 주제
- 요구 범위가 달라도 **핵심 개념이 같으면** 묶는다.
  - `SLOSS 논쟁이란?` / `SLOSS에서 큰 패치가 유리한 이유` → 같은 그룹
- 같은 법조문·같은 계산식·같은 분류체계를 묻는 것도 묶는다.

### 따로 둔다
- **답이 다른 개념**이면 절대 묶지 않는다. 발문이 똑같아도 마찬가지다.
  - `다음 설명에 해당하는 용어를 쓰시오` 라는 발문이 같아도
    답이 편향천이 / LID / 자기설계적 복원이면 **셋 다 따로**
- 같은 법이라도 **다른 조문**이면 따로.
  - 「습지보전법」의 계획 체계 ≠ 「습지보전법」의 습지보호지역 시설
- 같은 분야라도 **묻는 대상이 다르면** 따로.
  - 생태통로의 기능 ≠ 생태통로의 설치 기준 ≠ 생태통로 조성 전 조사항목

### 애매하면 따로 둔다
잘못 묶으면 "빈출 5회"라는 거짓 정보가 되고, 대조 화면에 엉뚱한 문항이 뜬다.
따로 두면 그냥 "1회 출제"가 될 뿐이라 손해가 작다.

## 대부분은 1문항짜리 그룹이다
726문항 중 되풀이되는 것은 일부다. **혼자인 문항이 많은 게 정상이다.**
억지로 묶지 마라.

## 출력 형식

```json
[
  {"group": "복원·복구·대체의 구분", "pks": [396, 812, 1043]},
  {"group": "편향천이", "pks": [1107]},
  {"group": "저영향개발(LID)", "pks": [734]}
]
```

- `group`: 주제를 알아볼 수 있는 짧은 이름 (화면에는 안 나오지만 검토에 쓴다)
- `pks`: 그 주제에 속한 문항 pk 목록. **1개짜리도 반드시 포함**
- **담당 파일의 모든 pk가 정확히 한 번씩** 들어가야 한다.
  빠뜨리거나 두 그룹에 넣으면 로더가 거부한다.
