## 제5장. 생태조사 방법론과 정량 분석

생태환경조사분석에서 이 장이 차지하는 위치는 명확하다. 앞의 1~4장이 "생태계가 어떻게 작동하는가"를 다루었다면, 5장은 **"그 생태계를 어떻게 측정하고 숫자로 표현할 것인가"** 를 다룬다. 실제 출제를 보면 이 영역은 크게 세 갈래로 나뉜다. 첫째는 **법정 조사 절차**로, 환경영향평가서 작성 규정이 정한 12개 분류군 구분과 현지조사표 작성 원칙이 그대로 출제된다. 둘째는 **계산 문항**으로, 포획-재포획법·유사도지수·귀화율·녹지자연도 비율이 매 회차 1~2문항씩 반드시 나온다. 셋째는 **평가 기준표**로, Braun-Blanquet 우점도 계급과 식생보전등급 평가항목이 표의 수치까지 그대로 물어진다.

> ⚠️ **장 구성 조정 사항**: 본래 배정된 주제 중 "동물상 조사(포유류·조류·양서파충류·어류·곤충의 분류군별 조사법과 조사 시기)"는 2022~2025년 기출 220문항 전체에서 **분류군별 조사법·조사시기를 직접 묻는 문항이 0건**이었다. 대신 조사 관련 출제는 ① 환경영향평가 조사 규정(12개 분류군 구분·현지조사표 작성법), ② GPS/GIS 기반 행동권 조사(MCP·KDE), ③ 지표종을 이용한 오염도 판정, ④ 정량지수 계산에 집중되어 있다. 따라서 장 제목을 「조사 방법론」에서 「**생태조사 방법론과 정량 분석**」으로 조정하고, 절 구성도 실제 출제 분포에 맞추어 재편하였다. 다만 분류군별 조사법은 12개 분류군 체계를 이해하는 데 필요한 최소한의 배경으로 5.2.3에 압축 수록하였다.

### 5.1 환경영향평가 자연생태환경 조사 체계

#### 5.1.1 동·식물상 조사의 목적

환경영향평가에서 동·식물상 조사를 왜 하는가라는 물음은 시험에 그대로 출제된다. 조사의 결과물로 종 목록이 만들어지고 개체군 밀도가 산출되기는 하지만, **그것들은 어디까지나 수단이자 중간 산출물**이다. 궁극적인 목적은 사업 시행으로 훼손될 수 있는 서식지와 종을 사전에 파악하여 저감방안과 대체서식지 조성 계획을 마련함으로써 **지역의 종다양성을 보전**하고 생태계 건전성을 유지하는 데 있다.

이 구조를 놓치면 "생물 이름의 목록화"나 "생물자원의 밀도 파악"을 목적으로 착각하기 쉽다. 목록과 밀도는 보전 판단을 내리기 위한 근거자료이지 그 자체가 목표가 아니다. 한편 **외래종 서식지의 확보**는 목적이 될 수 없을 뿐 아니라 방향이 정반대다. 생태계교란 생물은 확산을 억제하고 제거하는 것이 저감방안으로 제시되는 대상이기 때문이다.

**관련 문제**: (2025-2-14)

#### 5.1.2 조사 분류군 구분 — 12개 분류군

「환경영향평가서 등 작성 등에 관한 규정」은 자연생태환경 조사를 **총 12개 분류군**으로 구분하여 조사하는 것을 원칙으로 삼는다. 이 12라는 숫자와 세 갈래의 묶음 방식은 그대로 암기 대상이다.

| 대분류 | 세부 분류군 | 개수 |
|--------|------------|------|
| 식물 | 식물상, 식생 | 2 |
| 동물 | 포유류, 조류, 양서류, 파충류, 곤충류 | 5 |
| 수생태 | 어류, 무척추동물, 동물플랑크톤, 식물플랑크톤, 부착조류 | 5 |
| **합계** | | **12** |

다만 이 구분은 절대적인 것이 아니라, **조사지역의 자연환경 및 사업 특성에 따라 변경할 수 있다**. 예를 들어 육상 개발사업에서 수생태 분류군의 비중을 줄이거나, 양서류와 파충류의 조사표 양식을 병합해 사용하는 것이 허용된다.

**관련 문제**: (2025-2-20)

#### 5.1.3 현지조사표 작성 원칙

현지조사표는 조사의 신뢰성을 담보하는 법정 서식이다. 출제 포인트는 **"어디서, 누가, 어느 정밀도로 작성하는가"** 세 가지에 집중된다.

[ **작성 장소 — 현장 수기 작성이 원칙** ]

가장 빈번하게 함정으로 등장하는 지점이다. 현지조사표는 조사지점(지역·경로·구역)별로 **조사대상지 현장에서 수기로 직접 작성**하는 것이 원칙이다. "현장조사 후 사무실에서 정리하여 작성한다"는 서술은 틀린 것이다. 현장에서 즉시 기록해야 관찰 사실의 왜곡과 기억에 의한 보정을 막을 수 있기 때문이다. 다만 **실내동정이 필요한 사항은 예외**로 인정된다. 미세한 형질 확인이 필요한 곤충·플랑크톤 등은 현장에서 종 수준까지 확정할 수 없기 때문이다.

[ **작성 주체 — 자격과 서명** ]

조사자는 환경영향평가업자의 **상시 근무자**로서 자연생태환경 분야 **환경영향평가기술자(환경영향평가사 포함)**여야 하며, 현지조사표 작성 후 **서명**하여야 한다. 자격 없는 인력의 대리 조사나 무기명 조사표를 차단하기 위한 규정이다.

[ **기록 정밀도** ]

- **조사위치**: 지점명(구간 또는 범위 등), 좌표, 조사면적을 기록한다.
- **조사일시**: 현장에서 실제 조사한 시간까지 **분 단위**로 기록한다. "시 단위"가 아니라 분 단위라는 점이 출제된다.
- **조사방법**: 분류군별 특성에 따라 직접·간접 등 다양한 방법을 활용한다.
- **조사내용**: 각 분류군별 양식에 따라 가급적 자세하게 현장 기록하되, **서식(양식)에 없는 중요한 사항이나 특이사항이 있을 시 별도 기록**한다. 주요 종 정밀조사 시에는 별도 양식을 활용해 상세 기록할 수 있다.
- **종명**: **국명 기재를 원칙**으로 하며, 필요시 학명 등을 병기한다.
- **탐문조사**: 주민 등을 통한 탐문조사 시에는 탐문 대상자의 개략 인적사항을 기록한다.

[ **자료 증빙** ]

현지조사를 증명할 수 있는 자료를 현지조사표와 함께 보관해야 한다. 조사자·조사일자를 증명하는 **출장신청서, 차량 운행일지, 고속도로 통행 영수증, 동영상 자료** 등이 이에 해당하며, 현지조사 사진은 분류군 또는 현장을 확인할 수 있도록 촬영하여 보관한다. 사업유형이나 현지여건 때문에 현지조사표를 작성할 수 없는 경우에는 **그 사유를 구체적으로 작성하여 보관**해야 한다.

**관련 문제**: (2025-2-20)

#### 5.1.4 경관 분야 조사·분석 항목의 경계

환경영향평가는 분야별로 조사 항목이 나뉘어 있어, 어떤 항목이 어느 분야에 속하는지를 구분하는 문제가 출제된다. **경관배열(landscape configuration)**에 대한 조사·분석은 대상지역을 구성하는 경관요소(패치·코리더·매트릭스)가 공간적으로 어떻게 배치되어 있고 그것이 시각적·생태적으로 어떤 의미를 갖는지를 다루는 항목이다. 따라서 다음 세 가지가 경관 분야에 해당한다.

- 대상지역의 **시각적 조망권과 경관축** 분석
- 주요 생태자원의 **공간적 연결성(생태네트워크)** 고려
- **시설물의 배치가 주변경관과 조화**를 이루는지 검토

반면 **사업부지 내 지질구조와 암반 성분의 정밀 분석**은 '지형·지질' 분야 또는 토목 설계를 위한 지반조사 항목에 속하며 경관배열 분석과는 직접적 관련이 없다. 판별 요령은 간단하다. **"공간적 배치와 눈에 보이는 관계를 다루는가"** 를 기준으로 삼으면 된다.

**관련 문제**: (2025-2-13)

#### 5.1.5 경관 공간구조 분석 항목과 자료

경관의 공간구조를 분석할 때 검토해야 할 사항 역시 반복 출제된다. Forman & Godron의 **patch-corridor-matrix 모델**을 기반으로 다음을 분석한다.

- 패치·매트릭스·코리더의 **공간적 배치와 분포**
- 서식지와 생태적 기능 유지에 중요한 **경관연결성**
- 인간 활동이나 자연적 변화로 경관이 여러 개의 작은 조각으로 나뉘는 **파편화 현상**

여기에 **유전적 다양성 분석은 포함되지 않는다**. 유전적 다양성은 종 내부의 유전자 변이에 관한 개념으로 집단유전학(population genetics)의 영역이며, 경관구조의 '결과'로 나타나는 지표일 수는 있어도 공간적 패턴을 '직접' 평가하는 항목은 아니다. 경관유전학(landscape genetics)에서 경관구조와 연계해 다루기는 하지만 공간구조 분석 항목 자체는 아니라는 점을 구분해야 한다.

[ **분석에 사용하는 자료** ]

경관의 공간구조(패치·경계·연결성)를 분석하는 데 가장 적절한 자료는 **경관식생도(현존식생도)**이다. GIS 상에서 폴리곤 단위로 식생유형이 구분되어 있어 패치 면적·둘레·형태지수·패치 밀도·최근린거리·경계길이 등 각종 경관지수를 곧바로 산출할 수 있기 때문이다. 이에 비해 **기후변화 시나리오 자료**는 시간축 예측자료, **수질오염 분포도**는 수환경 항목, **토양입도 분석도**는 토양물리 항목이어서 공간구조 분석의 직접 자료가 되지 못한다.

**관련 문제**: (2025-1-9), (2025-2-19)

#### 5.1.6 야생동물 경관구조 분석지표

야생동물 경관구조 분석은 서식지의 공간적 패턴이 야생동물의 이동·분포·개체군 동태에 미치는 영향을 연구하는 과정이다. 서식지 단편화, 연결성, 서식지 질을 정량적으로 평가하는 데 사용하는 지표는 다음과 같다.

| 지표 | 설명 | 분석목적 |
|------|------|----------|
| 패치 크기(Patch Size) | 서식지 패치의 면적 | 서식 가능 여부 평가 |
| 패치 밀도(Patch Density, PD) | 일정 지역 내 패치 개수 | 서식지 분포 파악 |
| 가장자리 효과(Edge Density, ED) | 패치 경계선의 밀도 | 가장자리 생태 영향 분석 |
| 형태지수(Shape Index, SHAPE) | 패치의 복잡성 | 복잡한 서식지 형태 분석 |
| 연결성지수(Connectivity Index) | 패치 간 연결성 수준 | 야생동물 이동 가능성 평가 |
| 핵심 서식지(Core Area Index) | 내부 핵심 서식지 면적 비율 | 안정적 서식지 평가 |

여기서도 **개체군의 유전적 다양성**은 경관구조의 공간적 패턴을 직접 평가하는 지표가 아니다. 이 지표들은 FRAGSTATS 같은 경관지수 산정 프로그램으로 계산하는 것이 일반적이다.

**관련 문제**: (2025-1-12)

#### 5.1.7 GAP 분석과 서식지 평가 기법의 구분

서식지 보전 계획에 활용되는 분석 기법들은 이름이 비슷해 혼동하기 쉬우므로 **목적을 기준으로** 구분해야 한다.

| 기법 | 목적 | 특징 |
|------|------|------|
| **HSI**(Habitat Suitability Index) | 서식지의 **생태적 질** 평가 | 서식지 적합성을 0~1 점수로 평가하는 단일 지표. 보호공백 분석 목적이 아님 |
| **GAP 분석** | 보호지역과 중요 서식지 사이의 **보호공백(Gap)** 탐색 | 서식지의 공간적 분포·크기·연결성·파편화를 종합 평가. 보호가 필요한 지역과 현재 보호지역 간의 차이를 분석해 보전전략·토지계획에 활용 |
| **시나리오 분석** | **미래 예측** | 미래 토지이용·기후변화·개발계획에 따른 변화 예측. 현 시점의 공백 분석과 목적이 다름 |
| **생태네트워크 분석(EN)** | 생태축·핵심지역·연결통로 분석 | GAP과 유사한 공간 요소를 다루나 보호공백을 찾아 정책적 대응 여부를 판단하는 목적은 아님 |

출제 지문의 핵심 표현은 **"현 시점에서 야생동물의 서식적합지역의 크기·형상·배치 및 연결고리 상황을 파악함으로써 현재 대책에 차이(공백)가 없는지를 살피고, 향후 적합한 서식지를 보전·창출하며, 이 결과를 토지이용계획에 반영"**이다. 여기서 **'현 시점'**과 **'현재 대책의 차이'**라는 두 단서가 GAP 분석을 가리킨다.

**관련 문제**: (2025-1-6)

### 5.2 생물 조사 방법과 지표종 활용

#### 5.2.1 하천생태계 조사 방법

하천생태계 조사는 생물 조사와 물리·화학적 환경조사를 병행하여 하천 건강성을 종합 평가하는 방식으로 이루어진다.

[ **어류 조사** ]

종 구성, 개체수, 크기 분포를 통해 하천의 수질 상태와 서식지 건강성을 평가한다. 채집 방법으로 **전기충격기(electrofishing), 투망, 족대(반두), 자망** 등 다양한 방법이 사용된다. 크기 분포를 조사하는 이유는 개체군의 연령구조를 통해 재생산이 정상적으로 이루어지고 있는지를 판단할 수 있기 때문이다. 특정 크기군이 결손되어 있다면 산란장 훼손이나 이동 단절을 의심할 수 있다.

[ **수변식생 조사** ]

하천 주변의 식생 구조와 식물군집 특성을 분석하여 **하천 생태계와 육상 생태계 간의 연계성**을 평가한다. 수변식생은 단순한 육상 식생이 아니라 수생태계에 직접 영향을 주는 요소이므로 하천 조사의 필수 항목이 된다.

[ **수질 및 물리적 환경조사** ]

**수온, 용존산소, 탁도, 유속, 하상구조** 등 물리·화학적 요인을 측정하여 생물 조사와 함께 종합 평가한다. 생물 자료만으로는 왜 그런 군집이 형성되었는지 설명할 수 없으므로 물리·화학 자료가 반드시 병행되어야 한다.

[ **저서성 대형무척추동물 조사** ]

저서곤충이 환경 변화에 민감성이 낮아 지표종으로 쓰기 곤란하다는 서술은 **완전히 반대**이다. 저서성 대형무척추동물(benthic macroinvertebrates)은 하천생태계 평가의 **핵심 지표**로 활용된다. 그 이유는 다음 세 가지다.

- **이동성이 낮아** 특정 지점의 환경을 장기간 반영한다.
- **수명이 수개월~수년**으로 일시적 오염 사건까지 누적하여 기록한다.
- **분류군별 내성 범위가 뚜렷**해 오염 등급 판정이 가능하다.

우리나라 하천 건강성 평가에서도 **저서성대형무척추동물지수(BMI)**를 핵심 지표로 사용하며, **강도래·하루살이·날도래(EPT 분류군)**는 청정수역 지표, **깔따구류·실지렁이류**는 오염수역 지표로 활용된다.

**관련 문제**: (2025-3-13)

#### 5.2.2 지표종을 이용한 오염도 측정

오염 지표종은 민감종과 내성종의 상대적 구성 변화를 통해 오염도를 판정하는 데 쓰인다.

| 구분 | 특성 | 대표 분류군 |
|------|------|------------|
| **민감종**(sensitive species) | 수질 오염·저산소·중금속 등 환경변화에 매우 민감하게 반응. 오염도가 증가할수록 개체수가 감소하거나 서식지에서 사라짐 | 하루살이류, 강도래류, 날도래류 |
| **내성종**(tolerant species) | 오염된 환경에서도 잘 적응하여 살아남으며, 오염도가 높아질수록 개체수가 오히려 증가 | 깔따구류, 지렁이류, 일부 연체동물 |

민감종과 내성종을 **함께** 조사해야 특정 지역의 오염 수준과 생태계 건강성을 비교적 정확하게 평가할 수 있다. 한쪽만 보면 절대 개체수 변동과 오염 반응을 구분할 수 없기 때문이다.

[ **좋은 지표종의 조건 — 크고 오래 사는 종이 아니다** ]

출제에서 반복되는 함정은 "오염지표종은 일반적으로 크기가 크고 생활사가 길며 장기간의 환경 변화를 축적하여 반영한다"는 서술이다. 이는 **틀렸다**. 실제 오염지표종은 **크기가 작고 생활사가 짧으며 개체수 변동이 빠르고 민감한 종**이 대부분이다.

좋은 지표종의 조건은 다음과 같다.

- 분류·동정이 쉬울 것
- 분포가 널리 알려져 있을 것
- 환경 변화에 대한 반응이 **신속하고 명확**할 것
- 채집이 용이할 것

생활사가 짧아야 환경이 바뀌었을 때 개체군 반응이 빠르게 나타나 모니터링 주기에 맞춰 변화를 포착할 수 있다. 반대로 크고 수명이 긴 종은 반응이 지연되어 실시간 오염 판정에는 부적합하다.

> ⚠️ 앞의 5.2.1에서 저서성 대형무척추동물의 장점으로 "수명이 수개월~수년으로 오염 사건을 누적 기록한다"고 했는데, 여기서는 "생활사가 짧아야 좋다"고 하여 상충하는 듯 보인다. 두 서술은 층위가 다르다. **어류·조류처럼 수년~수십 년을 사는 대형 생물에 비하면 수개월~수년의 저서곤충은 충분히 '생활사가 짧은' 축**이며, 동시에 하루 단위로 물이 흘러가 버리는 **수질 측정값보다는 훨씬 긴 기간을 통합**한다. 즉 "수질 순간값보다는 길고, 대형 척추동물보다는 짧은" 시간 규모가 지표종의 최적 조건이다.

**관련 문제**: (2025-3-14)

#### 5.2.3 GPS·GIS를 이용한 행동권 조사

야생동물의 행동권(home range) 조사는 GPS 발신기로 위치 좌표를 수집하고 GIS로 공간분석하는 방식이 표준이 되었다.

[ **GIS의 역할** ]

- GPS 등으로 수집된 위치 좌표를 기반으로 **공간 데이터베이스를 구축**하여 개체의 이동 경로와 서식지 이용 패턴을 시각화한다.
- 지형·식생·수자원·인간 활동 등 **다양한 환경변수와 결합**하여 서식지 선호도 및 공간 활용 특성을 종합적으로 해석한다.

[ **행동권 산출 기법** ]

| 기법 | 원리 | 산출물 |
|------|------|--------|
| **MCP**(Minimum Convex Polygon, 최소볼록다각형) | 위치점의 외곽을 잇는 최소 볼록 다각형의 면적 | 전체 활동 범위. 계산이 단순하나 실제 이용하지 않는 공간까지 포함하는 과대추정 경향 |
| **KDE**(Kernel Density Estimation, 커널밀도추정) | 위치점의 밀도 분포를 확률면으로 추정 | **핵심서식지(core area, 통상 50% 등고선)**와 **전체 행동권(95% 등고선)**을 구분 |

[ **24시간 연속 기록이 필수인가 — 아니다** ]

출제 함정은 "GIS를 이용한 행동권 조사는 반드시 24시간 연속으로 위치를 기록해야만 의미가 있으며 특정 시간대나 부분적 자료로는 분석할 수 없다"는 서술이다. 이는 **틀렸다**. 실제로는 연구 목적과 종의 생활사에 따라 **특정 시간대(주행성·야행성 구분 등)나 계절별 자료만으로도 행동권 분석이 가능**하다. MCP·KDE 모두 **표본 위치점의 수와 독립성이 확보되면 간헐적 기록으로도 통계적으로 유효한 결과**를 산출한다. 오히려 연속 기록은 위치점 간 자기상관(autocorrelation)을 키워 통계적 독립성을 해칠 수 있다.

**관련 문제**: (2025-3-4)

#### 5.2.4 GIS·RS를 이용한 동물종 조사의 한계

야생생물 이동통로 조성을 위한 조사에서 GIS와 RS(원격탐사)의 장점은 분명하다.

- **광역 효율성**: 넓은 지역을 효율적으로 분석하여 특정 종의 서식 분포와 주요 이동 경로를 예측한다.
- **다중 자료 결합**: 위성영상·항공사진 등 다양한 공간 자료를 결합하여 지형·식생·토지이용 등 환경 요인을 정밀 파악한다.
- **접근 불가 지역 평가**: 현장조사로 접근하기 어려운 지역에서도 간접적으로 서식 가능성을 평가하여 이동통로 설치 위치를 과학적으로 도출한다.

그러나 **"모든 동물종을 빠짐없이 조사할 수 있으며 별도의 현장 확인이나 표본 채집 없이도 전 종에 대한 정확한 서식 정보가 확보된다"는 서술은 틀렸다**. GIS와 RS는 어디까지나 **보조적인 분석도구**이며 반드시 현장조사와 병행해야 정확한 결과를 얻는다.

원격탐사는 식생 피복·토지이용·지형 같은 **서식지의 물리적 조건**을 광역적으로 파악하는 데는 뛰어나지만, 소형 포유류·양서파충류·곤충처럼 **위성 해상도로는 탐지되지 않는 종의 실제 출현 여부는 확인할 수 없다**. 따라서 표준적인 방법은 단계적 접근이다. **GIS·RS로 후보지를 선별(scoping) → 현장에서 무인센서카메라·족적조사·포획조사 등으로 검증**하는 순서를 따른다.

이 단계적 접근에서 현장 검증에 쓰이는 분류군별 조사법을 간략히 정리하면 다음과 같다. 직접 출제된 적은 없으나 12개 분류군 체계를 이해하는 배경이 된다.

| 분류군 | 주요 조사법 |
|--------|------------|
| 포유류 | 무인센서카메라, 족적(발자국)·배설물·식흔 등 흔적조사, 포획틀(live trap), 청문조사 |
| 조류 | 정점조사(point count), 선조사(line transect), 정목조사, 청음조사 |
| 양서·파충류 | 주간 답사조사, 야간 울음소리 청취, 함정트랩(pitfall trap), 산란처 확인 |
| 어류 | 전기충격기, 투망, 족대, 자망 |
| 곤충류 | 쓸어잡기(sweeping), 유아등(light trap), 함정트랩, 털어잡기(beating) |
| 식물상·식생 | 방형구법, 상관법, 노선조사 |

**관련 문제**: (2025-3-5)

### 5.3 식생조사법 — 방형구법과 Braun-Blanquet 우점도

#### 5.3.1 방형구법의 개념

**방형구법(Quadrat method)**은 조사지역 내에 일정 면적의 사각형 조사구(방형구, quadrat 또는 릴레베 relevé)를 설치하고 그 안에 출현하는 식물의 종류·개체수·피복 정도를 기록하는 식생조사의 기본 방법이다. 전수조사가 불가능한 넓은 면적을 표본조사로 대표하기 위한 기법이며, 방형구의 크기는 대상 식생의 층위에 따라 달라진다. 초본층은 1~4m², 관목층은 25m² 내외, 교목층은 100~400m² 규모를 사용하는 것이 일반적이다.

실제 출제에서는 **하천변에 2m² 크기의 방형구를 설치하고 그 안의 식물군락을 조사한 자료**가 제시되며, 이를 바탕으로 귀화율을 산출하는 계산 문항으로 이어진다(5.4.3 참조).

**관련 문제**: (2025-2-12)

#### 5.3.2 Braun-Blanquet 우점도 계급

**Braun-Blanquet 법**은 유럽 식물사회학(Zürich-Montpellier 학파)의 표준 식생조사법으로, 우리나라 식생조사에서도 널리 쓰인다. 방형구 내 각 종의 **수도(Abundance, 개체수)**와 **피도(Cover, 피복면적)**를 결합하여 7단계 계급으로 판정한다.

| 계급 | 수도(Abundance) | 피도범위(Cover) |
|------|-----------------|-----------------|
| **r** | 한 개 또는 수개의 개체 | 고려하지 않음 |
| **+** | 다수의 개체이며 | 조사구(Releve) 면적의 **5% 미만** |
| **1** | 어떤 경우나 조사구 면적의 5% 미만 / 많은 개체이면서 매우 낮은 피도 또는 보다 적은 개체이면서 보다 높은 피도 | **5% 미만** |
| **2** | 매우 풍부하며 피도 5% 미만 또는 조사구 내에서 피도 5~25% | **5~25%** |
| **3** | 수도를 고려하지 않으며 | **26~50%** |
| **4** | 수도를 고려하지 않으며 | **51~75%** |
| **5** | 수도를 고려하지 않으며 | **76~100%** |

이 표에서 반드시 붙잡아야 할 두 가지가 있다.

첫째, **2등급의 피도범위는 5~25%**이다. 이 값이 그대로 출제되었다. 26~50%(3등급), 51~75%(4등급), 76~100%(5등급)와 혼동하지 않아야 한다.

둘째, **3등급 이상부터는 개체수(수도)를 따지지 않고 피복면적(피도)만으로 판정한다**는 점이 이 방법의 구조적 특징이다. r·+·1·2 계급까지는 수도와 피도를 함께 고려하지만, 피도가 26%를 넘어서면 개체가 몇 개인지는 의미가 없어지고 얼마나 덮고 있는지만 남는다.

계급 간 피도 폭을 기억하는 요령은 **"25 - 25 - 25 - 25로 4등분"**이다. 2등급이 5~25%, 3등급이 26~50%, 4등급이 51~75%, 5등급이 76~100%로 각각 약 25%p씩 구간을 나누어 가지며, 5% 미만의 미소 출현만 r·+·1로 세분한 구조다.

**관련 문제**: (2023-2-16)

#### 5.3.3 군집(식물군락)의 명명 방법

식생조사 결과를 정리해 군집 단위를 설정할 때는 그 군집을 대표하는 **생태적 특성**을 근거로 이름을 붙인다. 대표적인 세 가지 방법은 다음과 같다.

**1) 우점종 기준 명명**
상대우점도가 가장 높은 종의 이름을 붙이는 방식으로 '신갈나무군락', '소나무-신갈나무군락'처럼 표기한다. **우리나라 현존식생도 작성에 가장 널리 쓰인다.**

**2) 생활형 기준 명명**
Raunkiaer의 생활형 분류(지상식물·지표식물·반지중식물·지중식물·일년생식물 등)나 **상관(physiognomy)**에 따라 '상록활엽수림', '낙엽활엽수림', '초원' 등으로 명명한다. 항공사진 판독이나 광역 식생도에서 유용하다.

**3) 출현빈도·표징종 기준 명명**
Braun-Blanquet의 식물사회학적 방법처럼 **특정 군집에만 높은 빈도로 나타나는 표징종(character species)·식별종**을 기준으로 군집 단위를 명명한다.

반면 **군집 내 개체의 나이순**은 군집 명명의 기준이 되지 못한다. 이는 개체군의 **연령구조(age structure)**를 분석하는 항목으로, 개체군 생태학의 영역이지 군집 분류의 기준이 아니다.

**관련 문제**: (2025-2-7)

#### 5.3.4 상관법과 현존식생도

**상관(相觀, physiognomy)**이란 식생을 멀리서 바라볼 때 드러나는 겉모습, 즉 우점하는 생활형과 층위 구조가 만들어내는 외관을 말한다. **상관법**은 이 외관을 기준으로 식생을 구분하는 방법으로, 개별 종의 동정 없이도 광역 구분이 가능해 항공사진·위성영상 판독과 결합하기 쉽다는 장점이 있다. 반면 정밀도가 낮아 종 조성 수준의 차이는 잡아내지 못한다.

**현존식생도(경관식생도)**는 이러한 조사 결과를 폴리곤 단위로 도면화한 것으로, 앞서 5.1.5에서 본 것처럼 GIS 상에서 경관지수를 산출하는 기초 자료가 된다. 또한 5.5의 녹지자연도 사정과 식생보전등급 평가도 모두 현존식생도를 전제로 이루어진다.

**관련 문제**: (2025-2-19)

### 5.4 정량 분석 — 다양도·유사도·개체군 크기 추정

#### 5.4.1 군집 다양도의 구성 요소

군집의 구조적 특징을 결정하는 요소는 세 가지로 정리된다.

- **종풍부도(species richness)**: 군집에 나타나는 **종의 수**
- **상대풍부도(relative abundance)**: 모든 종이 포함된 총 개체수에서 각 종이 차지하는 **백분율**
- **종균등도(evenness)**: 각 종에 속하는 개체수의 **균등한 정도**

**종다양도(다양도지수)**는 종풍부도와 균등도 **두 요소를 모두 포함**하는 개념이다. 종 수만 많다고 다양도가 높은 것이 아니라, 개체가 종들 사이에 고르게 배분되어 있어야 다양도가 높게 산출된다. 이 점이 출제 포인트다.

여기서 **멸종위기종의 존재 여부**는 군집구조 특징의 결정요인이 아니다. 멸종위기종은 보전가치·법적 보호 등급을 판단하는 기준이지, 군집의 구조적 특징(풍부도·다양도·균등도)을 수량적으로 규정하는 지표가 아니기 때문이다.

**관련 문제**: (2024-2-3)

#### 5.4.2 다양도지수 — 심슨지수와 샤논지수

종다양도는 대표적으로 두 가지 지수로 계산한다.

[ **심슨지수(Simpson's index, D)** ]

**D = Σ(nᵢ/N)²**

여기서 nᵢ는 i종의 개체 수, N은 총 개체 수이다. 이 식이 산출하는 값은 **임의로 두 개체를 뽑았을 때 같은 종일 확률**이므로, 값이 클수록 특정 종이 독점하고 있다는 뜻이 되어 **다양도는 낮다**. 따라서 실무에서는 다양도가 높을수록 값이 커지도록 **D' = 1 - Σpᵢ²** 형태로 변형하여 사용하는 경우가 많다.

[ **샤논지수(Shannon index, H')** ]

**H' = −Σ Pᵢ log Pᵢ**   (Pᵢ = Nᵢ/N)

여기서 Pᵢ는 상대풍부도, Nᵢ는 i종의 개체 수, N은 총 개체 수이다. 정보이론에 근거한 지수로, 종풍부도와 균등도를 함께 반영한다. 값이 클수록 다양도가 높다.

두 지수의 성격 차이는 **가중치**에 있다. 심슨지수는 제곱 항 때문에 **우점종의 영향을 크게 반영**하는 반면, 샤논지수는 로그를 취하므로 **희소종의 존재까지 비교적 고르게 반영**한다.

**관련 문제**: (2023-3-15), (2024-2-3), (2024-3-2)

#### 5.4.3 유사도지수 계산 — 자카드와 쇠렌센

두 군집이 얼마나 닮았는지를 나타내는 지수로, 계산 문항으로 직접 출제된다.

[ **자카드 유사도지수(Jaccard similarity index)** ]

**유사도 = |X ∩ Y| / ( |X| + |Y| − |X ∩ Y| )**

여기서 |X|는 A군집의 종수, |Y|는 B군집의 종수, |X ∩ Y|는 두 군집에 공통으로 출현하는 종수이다.

**[기출 대입]** A군집 16종, B군집 18종, 동일 종 5종일 때

**자카드 유사도 = 5 / (16 + 18 − 5) = 5 / 29 = 0.172**

분모에서 공통종을 한 번 빼주는 이유는 |X|와 |Y|를 단순히 더하면 **공통종이 두 번 계산되기 때문**이다. 자카드 지수는 두 군집의 합집합 종수 대비 공통종의 비율을 나타내며, **0(전혀 공통종 없음)부터 1(완전히 동일)**까지의 값을 가진다.

[ **쇠렌센 지수(Sørensen index)** ]

**쇠렌센 지수 = 2c / (a + b)**   (a·b = 각 군집 종수, c = 공통종 수)

같은 자료를 대입하면 2×5/(16+18) = 10/34 = **0.294**이다. 쇠렌센 지수는 **공통종에 두 배의 가중치**를 주므로 자카드 지수보다 **항상 큰 값**을 가진다. 두 지수 중 어느 것을 묻는지 확인하지 않고 계산하면 오답이 되므로, 문제에서 "자카드"인지 "쇠렌센"인지를 먼저 확인해야 한다.

**관련 문제**: (2023-1-17)

#### 5.4.4 귀화율 계산

**귀화율(%)**은 특정 지역의 식생 교란 정도를 나타내는 대표적 지표로, 값이 높을수록 인위적 간섭이 크고 자연성이 낮은 지역임을 의미한다. **도시화지수(UI)**와 함께 사용된다.

**귀화율(%) = 귀화식물수(또는 개체수) / 전체 식물수(또는 개체수) × 100**

귀화율은 **종수 기준** 또는 **개체수 기준** 두 가지로 계산할 수 있으므로, 문제에서 어떤 자료가 주어졌는지를 먼저 확인해야 한다.

**[기출 대입]** 하천변 2m² 방형구 조사 결과

| 번호 | 식물명 | 개체 수 | 비고 |
|---|---|---|---|
| 1 | 망초(*Erigeron annuus*) | 11 | 귀화식물 |
| 2 | 환삼덩굴(*Humulus japonicus*) | 9 | 귀화식물 |
| 3 | 기린초(*Sedum kamtschaticum*) | 4 | 자생식물 |
| 4 | 개망초(*Erigeron philadelphicus*) | 3 | 귀화식물 |
| 5 | 애기달맞이꽃(*Oenothera laciniata*) | 7 | 귀화식물 |
| 6 | 소리쟁이(*Rumex crispus*) | 6 | 자생식물 |

개체수 자료가 주어졌으므로 **개체수 기준**으로 계산한다.

- 총개체수 = 11 + 9 + 4 + 3 + 7 + 6 = **40개체**
- 귀화식물 개체수 = 11(망초) + 9(환삼덩굴) + 3(개망초) + 7(애기달맞이꽃) = **30개체**

**∴ 귀화율 = 30 / 40 × 100 = 75.0%**

참고로 **종수 기준**으로 계산하면 4/6 × 100 ≒ **66.7%**가 되어 답이 달라진다. 개체수 자료가 제시되었다면 개체수 기준으로 푸는 것이 출제 의도이다.

**관련 문제**: (2025-2-12)

#### 5.4.5 포획-재포획법에 의한 개체군 크기 추정

이동성이 큰 어류·포유류·조류의 개체군 크기를 추정하는 표준 기법으로, **매년 계산 문항으로 출제**되는 최빈출 공식이다.

[ **Lincoln-Petersen 지수** ]

**N = (M × C) / R**

- **M**: 1차 포획하여 표지한 개체수
- **C**: 2차 포획한 총 개체수
- **R**: 2차 포획 개체 중 표지된 개체수
- **N**: 추정 개체군 크기

비례식 형태로 쓰면 다음과 같다.

**M / N = R / C**

즉 **"전체 중 표지 비율"이 "재포획 표본 중 표지 비율"과 같다**는 것이 원리다.

**[기출 대입 ①]** 호수에서 100마리의 베스를 포획·표식 후 방류. 얼마 후 150마리를 포획했더니 표식 개체가 50마리였다.

**100 / N = 50 / 150  →  N = 100 × (150 / 50) = 300마리**

**[기출 대입 ②]** 무지개송어 110마리를 포획·표식 후 방류. 189마리를 재포획했더니 그중 63마리가 표식 개체였다.

**N = (110 × 189) / 63 = 330마리**

[ **전제 가정 3가지** ]

이 방법은 다음 세 가지 가정 위에서만 성립하므로, 가정을 묻는 문항에 대비해야 한다.

1. **표지가 개체의 생존·행동에 영향을 주지 않을 것** — 표지 때문에 포식당하기 쉬워지거나 행동이 달라지면 추정이 왜곡된다.
2. **조사기간 중 출생·사망·이입·이출이 없을 것(폐쇄개체군)** — 두 조사 시점 사이에 개체군 크기가 변하지 않아야 한다.
3. **표지 개체가 개체군 내에 고르게 섞일 것** — 표지 개체가 한곳에 몰려 있으면 재포획 비율이 편향된다.

**관련 문제**: (2023-3-10), (2024-3-5)

#### 5.4.6 개체군 성장률 계산 — 로지스틱 모형

**dN/dt = rN (1 − N/K)**

- **N**: 개체군 크기, **r**: 개체군 증가율(내적자연증가율), **K**: 환경수용력

**[기출 대입]** N = 200, r = 0.5, K = 2,000일 때

**dN/dt = 0.5 × 200 × (1 − 200/2,000) = 0.5 × 200 × 0.9 = 90**

로지스틱 성장모형은 자원이 한정된 실제 환경에서의 개체군 성장을 기술하는 모형으로 **S자형(sigmoid) 곡선**을 그린다. 여기서 **(1 − N/K)** 항은 **'환경저항'** 또는 **'미이용 잔여 수용력'**을 의미한다. N이 K에 비해 매우 작을 때는 이 항이 1에 가까워져 지수성장(dN/dt ≒ rN)에 근접하고, N이 K에 접근하면 0에 수렴하여 성장이 멈춘다.

성장률이 **최대가 되는 지점은 N = K/2**일 때이며, 이 개념은 수산자원의 **최대지속가능수확량(MSY, Maximum Sustainable Yield)** 산정의 이론적 근거가 된다.

**관련 문제**: (2024-1-10)

#### 5.4.7 생산량 계산 — GPP·NPP·현존량

생산성 계산은 4장의 에너지 흐름과 연결되지만, 조사·분석 과목에서는 **주어진 자료로 값을 산출하는 계산 기법**으로 출제되므로 여기에 함께 정리한다.

[ **기본 관계식** ]

**Pn = Pg − R**   (NPP = GPP − R)

- **총생산량(Pg, GPP)**: 광합성으로 생산된 총에너지
- **호흡량(R)**: 식물이 생존을 위해 소비한 에너지
- **순생산량(Pn, NPP)**: 생장·축적되는 실제 생산량

**R = Pg − Pn** 역시 위 식을 이항한 동치 관계식이지만, 기본형을 묻는 문제에서는 **Pn = Pg − R**을 정답으로 한다. 또한 호흡량 R은 항상 양수이므로 **NPP가 GPP보다 커지는 경우는 존재하지 않는다**. 육상 생태계에서 NPP/GPP 비율은 대체로 **0.4~0.6** 수준이며, 성숙림일수록 호흡 소비 비중이 커져 이 비율이 낮아진다.

[ **기출 대입 ① — 순생산량과 P/R률 표 계산** ]

| 구분 | 초지 | 산림 |
|---|---|---|
| 총광합성량 | 24,000 | 48,000 |
| 독립영양생물호흡량 | 8,000 | 12,000 |
| 순생산량 | ⓐ | ⓑ |
| 종속영양생물호흡량 | 4,000 | 8,000 |
| P/R률 | ⓒ | ⓓ |

- ⓐ(초지) = 24,000 − 8,000 = **16,000**
- ⓑ(산림) = 48,000 − 12,000 = **36,000**
- ⓒ(초지) = 24,000 ÷ (8,000 + 4,000) = 24,000 ÷ 12,000 = **2.0**
- ⓓ(산림) = 48,000 ÷ (12,000 + 8,000) = 48,000 ÷ 20,000 = **2.4**

여기서 주의할 점은 **순생산량은 독립영양생물 호흡만 빼지만, P/R률의 분모는 독립영양+종속영양 호흡을 모두 더한 총호흡량**이라는 것이다. 이 구분을 놓치면 ⓒ·ⓓ가 틀린다.

[ **기출 대입 ② — 생장량·고사량·피식량으로부터 NPP·GPP 산출** ]

생장량 75.4, 고사량 3.2, 피식량 7.5, 호흡량 24.4 gC/m²/yr일 때

**NPP = 75.4 + 3.2 + 7.5 = 86.1 gC/m²/yr**

**GPP = NPP + R = 86.1 + 24.4 = 110.5 gC/m²/yr**

순1차생산량은 **식물체에 실제로 남은 생장량뿐 아니라, 이미 죽어 떨어진 고사량과 초식동물에게 먹힌 피식량까지 모두 합해야 한다**. 이들은 모두 광합성으로 고정된 뒤 호흡으로 소모되지 않고 유기물로 남은 양이기 때문이다. **고사량과 피식량을 빠뜨리고 생장량만 NPP로 잡으면 오답**이 되므로 주의해야 한다.

[ **기출 대입 ③ — 2차생산에 따른 현존량** ]

총광합성량 150, 호흡량 50, 에너지효율 10%, 현존량 200일 때

- NPP = GPP − R = 150 − 50 = **100**
- 2차생산량 = 100 × 10% = **10**
- 2차생산에 따른 현존량 = 200 + 10 = **210**

영양단계 간 에너지 전달효율은 통상 10% 내외(**린데만의 10% 법칙**)이므로, NPP 100 중 10만이 2차생산량으로 전환된다.

**관련 문제**: (2023-2-5), (2024-1-9), (2025-1-4), (2025-1-20), (2025-3-9)

#### 5.4.8 슬러지 시용량 계산

토양 개량제·비료로서 슬러지를 시용할 때 필요량을 계산하는 문항이다. **수분함량 → 건물 비율 → 질소 함유율 → 유효율**의 4단계를 순서대로 곱해 나가면 된다.

**[기출 대입]** 슬러지 내 수분함량 40%, 건슬러지 질소 비율 5%, 질소 효율성 40%. 3kg의 질소가 필요할 때 슬러지 소요량은?

1. 수분함량 40% → **건물(고형물) 비율 60%**이므로 슬러지 1kg 중 건슬러지 = 0.6kg
2. 건슬러지의 질소 함유율 5% → 질소 총량 = 0.6 × 0.05 = **0.03kg**
3. 질소 유효율 40% → 유효질소 = 0.03 × 0.4 = **0.012kg/슬러지 kg**
4. 필요 유효질소 3kg ÷ 0.012 = **250kg**

**∴ 필요 슬러지량 = 250 kg**

**관련 문제**: (2024-1-11)

### 5.5 식생 평가 등급 — 녹지자연도와 식생보전등급

#### 5.5.1 녹지자연도 사정 기준

**녹지자연도(綠地自然度)**는 식생의 자연성 정도를 0~10등급으로 사정하는 지표로, 환경영향평가에서 개발 가능지와 보전지를 가르는 기준으로 활용된다. 아래 표는 환경부 「전략환경영향평가 업무매뉴얼」(2014.1)의 기준으로, **등급 숫자와 해당 식생형이 그대로 출제**된다.

| 지역 | 등급 | 개요 | 해당 식생형 |
|------|------|------|------------|
| 수역 | **0** | 수역 | 강, 호수, 저수지 등 수체가 존재하는 부분과 식생이 존재하지 않는 하중도·하안 포함 |
| 개발지역 | **1** | 시가지, 조성지 | 식생이 존재하지 않는 지역 |
| 개발지역 | **2** | 농경지(논, 밭) | 논, 밭, 텃밭 등의 경작지 / 비교적 녹지가 많은 주택지(녹피율 60% 이상) |
| 개발지역 | **3** | 농경지(과수원) | **과수원이나 유실수 재배지역 및 묘포장** |
| 개발지역 | **4** | 이차초원A(키 낮은 초원) | 2차적으로 형성된 키 작은 초원식생(골프장, 공원묘지, 목장 등) |
| 개발지역 | **5** | 이차초원B(키 큰 초원) | 2차적으로 형성된 키 큰 초원식물(묵밭 등 훼손지역의 억새군락·잡초군락) |
| 반자연지역 | **6** | 조림지 | 인위적으로 조림된 후 지속 관리되는 식재림 / 조림수종 70% 이상 우점 식생, 아까시나무림·사방오리나무림 등 도입종·개량종 우점 군락 |
| 반자연지역 | **7** | 이차림(Ⅰ) | 자연식생이 교란된 후 2차 천이로 회복단계에 들어섰거나 인간 교란이 심한 산림식생. 계층구조 불안정, 종조성이 잠재자연식생을 반영하지 못함 |
| 반자연지역 | **8** | 이차림(Ⅱ) | 자연식생이 교란된 후 2차 천이로 자연식생에 가까울 정도로 거의 회복된 삼림식생. 계층구조 안정, 종조성이 잠재자연식생 반영 |
| 자연지역 | **9** | 자연림 | 식생천이의 종국적 단계에 이른 극상림 또는 그와 유사한 자연림. 8등급 식생 중 평균수령 50년 이상 |
| 자연지역 | **10** | 자연초원, 습지 | 삼림식생 이외의 자연식생·특이식생(고산황원, 아고산초원, 습원, 하천습지, 염습지, 해안사구, 자연암벽 등) |

등급 체계를 기억하는 요령은 **네 개의 지역 구분**을 먼저 잡는 것이다. **0(수역) → 1~5(개발지역) → 6~8(반자연지역) → 9~10(자연지역)** 순으로, 인간 간섭이 클수록 낮고 자연성이 높을수록 큰 값을 갖는다. 특히 **10등급이 자연림이 아니라 자연초원·습지**라는 점이 함정이다. 극상림(9)보다 습원·염습지·해안사구 같은 특이식생을 더 높게 평가한다.

#### 5.5.2 녹지자연도 비율 계산

**[기출 대입 ①]** 자연림 60ha, 이차림 30ha, 이차초원 20ha, 과수원 40ha인 지역의 **3등급 비율**은?

녹지자연도 3등급은 **농경지(과수원)**이므로 해당 면적은 과수원 40ha이다.

**40 / (60 + 30 + 20 + 40) × 100 = 40 / 150 × 100 = 26.6%**

**[기출 대입 ②]** 현존식생조사 결과 밭 1km², 논 1km², 일본잎갈나무 조림지 1km², 20년 미만 상수리나무림 1km², 20년 이상 신갈나무림 1km². **녹지자연도 7등급 이상은 보전**하고 나머지는 개발 가능할 때 가용지 면적은?

각 식생의 등급을 판정하면 다음과 같다.

- 밭 1km² → **2등급**
- 논 1km² → **2등급**
- 일본잎갈나무 조림지 1km² → **6등급**
- 20년 미만 상수리나무림 1km² → **7등급**(보전)
- 20년 이상 신갈나무림 1km² → **8등급**(보전)

> ⚠️ **정답 처리 주의**: 등급표를 그대로 적용하면 6등급인 조림지도 개발 가능하여 가용지가 3km²가 되어야 하지만, 이 문제의 **정답은 2km²**로 제시되었다. 출제자가 **일본잎갈나무 조림지를 보전대상으로 간주**하여 농경지(2등급)인 밭 1km² + 논 1km² = 2km²만을 가용지로 산정한 것이다. 즉 "농경지만 개발 가능"으로 협의된 셈이다. 유사 문항에서는 **조림지의 처리 방향**을 문제 조건에서 먼저 확인해야 한다.

**관련 문제**: (2023-1-18), (2025-2-11)

#### 5.5.3 식생보전등급 평가항목

**식생보전등급**은 환경부 「자연환경조사방법 및 등급분류기준 등에 관한 규정」에 따른 평가 체계로, **평가항목 6가지**가 그대로 출제된다.

| 평가항목 | 평가요령 |
|---------|---------|
| **분포희귀성**(Rarity) | 평가대상 식물군락이 한반도 내에서 분포하는 패턴을 의미. **분포면적이 국지적으로 좁으면 높게, 전국적으로 분포하면 낮게** 평가 |
| **식생복원잠재성**(Potentiality) | 평가대상 식물군락(식분)이 형성되는 데 소요되는 기간(잠재 자연식생의 형성기간)을 의미. **오랜 시간이 요구되면 높게, 짧은 시간에 형성되면 낮게** 평가. 다만 식생 발달기원이 부영화·식재 등에 의한 것이면 상대적으로 낮게 평가 |
| **구성식물종 온전성**(Integrity) | 구성식물종(진단종군)이 해당 입지에 잠재적으로 형성되는 식물사회의 구성식물종인가를 평가. 삼림의 경우 **천이후기종(극상종)으로 구성되면 높게, 초기종 구성비가 높으면 낮게** 평가 |
| **식생구조 온전성** | 평가대상 식물군락이 해당 입지에 전형적으로 발달하는 식생구조(층위구조)와 얼마나 원형에 가까운가로 판정 |
| **중요종서식** | 식물종 자체의 보전생태학적 가치를 평가. 분포면적이 좁거나 **중요한 식물종(멸종위기야생생물 Ⅰ·Ⅱ급 또는 식물구계학적 중요종)**이 포함되면 더욱 높게 평가 |
| **식재림 흉고직경** | 식재림의 경우 가장 큰 개체, 보통 개체의 **흉고직경(DBH)**을 기록 |

출제 함정은 **"지역의 고유성"**이다. 그럴듯하게 들리지만 위 여섯 항목 어디에도 없으므로 평가항목이 아니다. 반대로 **"식재림 흉고직경"**은 언뜻 평가항목처럼 보이지 않지만 **정식 평가(기록) 항목에 포함**된다는 점이 반전 포인트다.

평가 방향을 관통하는 원리는 하나다. **"오래 걸려 만들어지고, 흔하지 않고, 원형에 가까울수록 높게"** 평가한다. 분포가 좁을수록(희귀성), 형성 기간이 길수록(복원잠재성), 극상종으로 구성될수록(구성종 온전성), 층위구조가 전형적일수록(구조 온전성) 보전 가치가 높다는 일관된 논리다.

**관련 문제**: (2023-1-19)

#### 5.5.4 잠재자연식생 — 평가의 기준선

식생보전등급의 '구성식물종 온전성'과 '식생구조 온전성'은 모두 **잠재자연식생**을 기준선으로 삼는다. 따라서 이 개념의 정확한 정의가 중요하다.

**잠재자연식생(potential natural vegetation, PNV)**은 독일의 식물사회학자 **튀크센(R. Tüxen)**이 제창한 개념으로, **현재의 입지조건(기후·토양·지형) 아래에서 인간의 간섭이 완전히 사라졌다고 가정할 때 최종적으로 성립하게 될 식생**을 말한다. 핵심은 **실제로 존재하는 식생이 아니라 '이론적으로 도달 가능한 극상식생'**이라는 점이며, 생태복원 시 **목표식생(target vegetation)**을 설정하는 기준으로 활용된다.

혼동하기 쉬운 인접 개념들을 함께 정리하면 다음과 같다.

| 용어 | 정의 |
|------|------|
| **식생**(vegetation) | 어느 지역의 땅 위를 덮고 있는 식물을 통틀어 이르는 말 |
| **자연식생**(natural vegetation) | 사람의 영향을 **전혀 받지 않고** 자연 그대로 유지된 식생 |
| **현존식생**(actual vegetation) | 훼손 여부와 관계없이 **현재 그 장소에 실제로 남아 있는** 식생 |
| **잠재자연식생**(PNV) | 인간의 간섭이 **사라졌을 때 자연적으로 형성될** 식생 |

**관련 문제**: (2024-3-10)

### 5.6 환경지표 체계

#### 5.6.1 환경지표의 개념과 요건

**환경지표**란 환경을 구성하고 있는 여러 부문의 관측값 중에서 **현상을 가장 잘 설명하는 대표치**를 말한다. 이상적인 환경지표가 되기 위해서는 **대표성**과 **과학적 타당성**을 갖추어야 한다.

부문별 지표의 예를 들면, **가축분뇨 발생량 및 처리현황, 수질현황, 폐수배출시설 및 배출량현황**은 모두 물환경 관련 지표가 될 수 있다.

여기서 반복 출제되는 함정은 **"환경상태를 측정하는 지표생물을 깃대종이라고 한다"**는 서술이다. 이는 **틀렸다**. 환경상태를 측정하는 지표생물은 **지표종(indicator species)**이다. 특수 지위 종들의 구분은 다음과 같다.

| 용어 | 정의 |
|------|------|
| **지표종**(indicator species) | 특정 환경조건의 변화에 민감하게 반응하여 **환경의 질을 판단하는 척도**가 되는 종 (예: 하천 수질 판정의 저서성 대형무척추동물, 대기오염 지표인 지의류) |
| **깃대종**(flagship species) | 지역 생태계를 대표하는 **상징적·심미적 가치**가 큰 종으로, 대중의 관심과 보전 참여를 이끌어내기 위해 선정 (예: 반달가슴곰, 수달) |
| **우산종**(umbrella species) | **행동권이 넓어** 그 종을 보호하면 동일 서식지의 다른 종까지 보호되는 종 |
| **핵심종(중추종)**(keystone species) | 개체수에 비해 생태계에 미치는 영향이 **압도적으로 큰** 종 |
| **희소종(희귀종)** | 야생상태에서 개체수가 특히 적은 종 |

**관련 문제**: (2023-3-16)

#### 5.6.2 OECD 환경지표 구성틀 — PSR 모형

OECD는 1991년 **압력-상태-대응(Pressure-State-Response, PSR)** 체계를 환경지표의 기본 틀로 제안하였다.

| 분류 | 정의 | 예 |
|------|------|-----|
| **원인/압력**(Pressure) | 인간의 활동, 생활과정과 삶의 유형 | 자원의 이용, 오염물질 배출량, 폐기물 발생량 등 |
| **상태**(State) | 원인에 의해 변화된 환경상태 | 오염된 공기 또는 물, 토양의 비옥도, 염화 및 침식 등 |
| **대응**(Response) | 환경변화에 대한 사회적 대응 | 법정·제도적 수단, 경제적 수단, 관리전략, 개발계획 및 전략 등 |

따라서 **Measure(측정)**는 OECD 환경지표 구성틀에 포함되지 않는다. P·S·R 세 글자만 기억하면 되는 단순한 구조이므로, 그럴듯한 네 번째 항목이 제시되면 그것이 오답이다.

[ **확장 모형** ]

- **DPSIR 모형**: EU 유럽환경청(EEA)이 PSR에 **동인(Driving force)**과 **영향(Impact)**을 추가하여 확장
- **DSR 모형**: UN이 사용하는 **동인(Driving force)-상태(State)-대응(Response)** 모형

**관련 문제**: (2023-3-17)

## 제6장. 물·토양 환경 조사와 원격탐사·GIS

5장이 "생물을 어떻게 세고 평가하는가"를 다루었다면, 6장은 **"생물이 살아가는 무대인 물과 토양을 어떻게 측정하고, 그 공간 정보를 어떻게 다루는가"** 를 다룬다. 출제 분포를 보면 이 장은 세 덩어리로 구성된다. 첫째, **수환경 조사**로 용존산소·수온 성층·부영양화·하천 차수가 반복 출제된다. 둘째, **토양 조사**로 토양수분 구분과 양분 이동성이 나온다. 셋째, 그리고 가장 비중이 큰 **원격탐사(RS)와 GIS**로, 매 회차 최소 1~2문항이 배정되며 위성 제원표·데이터 구조·좌표계가 표의 수치까지 그대로 물어진다.

> ⚠️ **장 구성 조정 사항**: 배정된 주제 중 "수질지표·하천 수생태 건강성"의 세부 항목(BOD·COD 기준치, 수생태 건강성 평가 등급 체계)과 "토성·pH·CEC" 중 **CEC(양이온교환용량)와 pH를 직접 묻는 문항은 0건**이었다. 반면 예상보다 훨씬 비중이 큰 것은 ① **호수의 수직 구조와 성층**(수온약층·보상심도·영양생성대/분해대), ② **부영양화 메커니즘과 저감대책**(4문항), ③ **원격탐사 위성 제원표**(동일 표가 2회 출제), ④ **GIS 구성요소·데이터 구조**(4문항)였다. 이에 절 구성을 실제 출제 분포에 맞추어 재편하고, 토양 파트는 출제된 **토양수분 3구분·수분항수·양분 이동성**을 중심으로 압축하였다.

### 6.1 수환경 조사 — 용존산소와 수직 구조

#### 6.1.1 용존산소(DO)의 개념과 단위

**용존산소(DO, Dissolved Oxygen)**는 물속에 용해되어 있는 산소량이며, 단위는 주로 **ppm(mg/L)**으로 나타낸다. 수생생물의 호흡에 직결되므로 수질 판정과 서식 가능성 평가의 1차 지표가 된다.

용존산소의 공급원은 두 가지다. **대기와의 접촉을 통한 재폭기(reaeration)**와 **수생식물·조류의 광합성**이다. 반대로 소비원은 생물의 호흡과 유기물 분해다. 이 공급과 소비의 균형이 수심에 따라 달라지기 때문에 호수에서는 뚜렷한 수직 분포가 나타난다.

기체의 용해도는 **수온이 올라갈수록 낮아지므로**, 지구온난화로 수온이 상승하면 용존산소는 **감소**한다. 이는 6.1.5에서 다루는 온난화의 수생태계 영향과 직결된다.

**관련 문제**: (2022-1-4)

#### 6.1.2 호수의 수직 성층 구조와 DO 분포

호수는 여름철 표층이 데워지면서 밀도 차이에 의해 세 개의 층으로 나뉘는 **성층(stratification)**을 형성한다.

| 층 | 명칭 | 특성 | 용존산소 |
|---|------|------|---------|
| 상층 | **표수층**(epilimnion) | 공기와 직접 접하고 광합성이 활발. 바람에 의해 잘 혼합됨 | **가장 높음** |
| 중간 | **수온약층**(metalimnion, thermocline) | 수온이 급격하게 변화하는 층. 상층부로부터 산소 공급이 차단되고 유기물 분해로 산소 소비 발생 | **급격히 감소** |
| 하층 | **심수층**(hypolimnion) | 빛이 도달하지 않아 광합성 불가. 표층과 물 교환 차단 | **소량만 존재** |

여기서 출제 함정은 **"수온약층에서 용존산소가 급격히 증가한다"**는 서술이다. 이는 **정반대**다. 수온약층은 위로부터의 산소 공급이 차단되는 동시에 침강하는 유기물의 분해로 산소가 소비되는 구간이므로 DO가 **급격히 감소**한다. 이 구간을 **산소약층(oxycline)**이라 부르기도 한다.

여름철 성층이 형성되면 심수층은 표층과 물 교환이 차단되어 용존산소가 고갈되고, 혐기 조건에서 **황화수소(H₂S), 메탄(CH₄), 암모니아(NH₄⁺)**가 축적되며 **퇴적물로부터 인이 재용출**되어 부영양화를 가속시킨다.

**관련 문제**: (2022-1-4)

#### 6.1.3 빛에 따른 수직 구분 — 영양생성대와 영양분해대

호수는 성층(수온 기준) 외에 **빛의 투과 정도**에 따라서도 수직 구분된다. 두 구분 체계는 서로 다른 기준이므로 혼동하지 않아야 한다.

[ **보상점과 보상심도** ]

**보상점(compensation point)**은 **광합성에 의한 산소 발생량과 호흡에 의한 산소 소비량이 일치하는 수심**이다. 이 지점을 경계로 **위쪽은 생산 영역, 아래쪽은 소비 영역**으로 구분된다. 이 깊이를 **보상심도(compensation depth)**라 한다.

[ **영양생성대(photic zone)** ]

보상심도 **위** 구간으로, **광합성 속도가 호흡 속도를 초과**하여 **순1차생산량(NPP)이 양(+)의 값**을 가진다. **식물플랑크톤과 부착조류**가 주요 생산자로 기능한다.

[ **영양분해대(aphotic zone, profundal zone)** ]

광합성에 필요한 광량이 부족하여 **동화작용이 불가능**하고, **혐기성 분해자(anaerobic decomposers)**에 의한 분해 과정이 우세하여 **황화수소(H₂S) 등이 축적**되기 쉽다.

[ **저층(저질, benthic zone)** ]

출제 함정이 집중되는 지점이다. **"저층은 광합성에 유리한 환경을 제공하여 수생식물의 뿌리내림과 지속적 산소 공급이 가능하고 유기물 축적이 거의 발생하지 않는다"**는 서술은 **틀렸다**. 실제 저층은 침강한 **퇴적물에 의해 유기물이 축적**되고, **광합성이 불가능하여 산소 고갈 현상이 쉽게 발생**한다. 저층은 호수에서 가장 환원적이고 유기물이 많이 쌓이는 구간이다.

**관련 문제**: (2025-3-20)

#### 6.1.4 내부파와 수직 혼합

**내부파(internal wave)**는 **밀도가 다른 두 수층의 경계면에서 발생하는 파동**이다. 이 파동이 부서지면서 발생하는 난류가 **수직 혼합**을 유도하며, 다음과 같은 연쇄 효과를 일으킨다.

- 두 수층의 **수직혼합**을 일으킴
- 저층의 풍부한 **영양염(NO₃⁻, PO₄³⁻ 등)을 상층에 공급**
- 그 결과 **표층의 식물플랑크톤 생산을 증가**시킴

여기서 구분해야 할 것이 **용승류(Upwelling)**다. 용승류는 내부파의 결과가 아니라, **지속적인 바람에 의한 에크만 수송(Ekman transport)이나 해류의 발산** 등에 의해 **심층수가 표층으로 올라오는 별개의 물리적 현상**이다. 두 현상 모두 심층 영양염을 표층에 공급한다는 결과는 비슷하지만 **발생 기작이 전혀 다르다**는 점이 출제 포인트다.

**관련 문제**: (2022-1-13)

#### 6.1.5 지구온난화에 따른 수생태계 변화

지구온난화가 수생태계에 미치는 영향은 네 가지 방향으로 나타나며, 그중 하나만 방향이 반대여서 출제된다.

| 변화 | 방향 | 기작 |
|------|------|------|
| 해수온도 | **상승** | 대기 온도 상승이 표층 해수로 전달 |
| 해수면 | **상승** | 극지 빙하 융해 + 해수의 열팽창 |
| 용존산소 | **감소** | 기체 용해도는 수온이 올라갈수록 낮아짐 |
| pH | **감소(산성화)** | 대기 CO₂ 증가 → 해수 용해 → 탄산(H₂CO₃) 형성 → H⁺ 방출 |

**"pH가 증가한다"**는 서술이 틀린 것이다. 대기 중 CO₂ 농도가 증가하면 바닷물에 용해된 CO₂가 늘어나 **탄산(H₂CO₃)**을 형성하고 **수소이온(H⁺)을 방출**하여 **해양 산성화(ocean acidification)**가 일어난다. 즉 pH는 증가가 아니라 **감소**한다.

해양 산성화는 **탄산칼슘(CaCO₃) 골격을 가진 산호·조개류·유공충의 석회화를 방해**해 생태계 전반에 영향을 준다.

**관련 문제**: (2023-3-8)

#### 6.1.6 오염물질 농도 단위

수질·토양 오염도를 표현하는 농도 단위는 환산 관계가 그대로 출제된다.

| 단위 | 비율 | 등가 표현 |
|------|------|----------|
| **ppm** | 백만분의 1 (10⁻⁶) | mg·L⁻¹, mg·kg⁻¹, g·m⁻³ |
| **ppb** | **십억분의 1 (10⁻⁹)** | **ng·g⁻¹, μg·kg⁻¹, μg·L⁻¹, mg·m⁻³** |
| **ppt** | 1조분의 1 (10⁻¹²) | pg·g⁻¹, ng·kg⁻¹, ng·L⁻¹, μg·m⁻³ |

출제된 정답 지문은 **"ppb : 십억분의 1에 해당되는 농도, ng·g⁻¹, μg·kg⁻¹, μg·L⁻¹, mg·m⁻³과 동일"**이다. 이 등가 관계가 성립하는 이유는 단순하다. 분자와 분모의 단위를 같은 비율로 조정하면 모두 10⁻⁹의 비율을 갖게 되기 때문이다.

함정으로 제시되는 오답은 **"ppm : 십만분의 1"**(→ 백만분의 1이 맞음)과 **"ppt : 십억분의 1"**(→ 1조분의 1이 맞음)이다. **백만-십억-일조**로 세 단계가 각각 1,000배씩 차이 난다는 것만 잡으면 된다.

**관련 문제**: (2022-2-10)

### 6.2 부영양화 — 기작·조건·저감대책

#### 6.2.1 부영양화의 개념과 진행 과정

**부영양화(eutrophication)**는 호수·강·저수지·해양 등의 수계에 **질소(N)와 인(P) 등의 영양염류가 과다하게 유입**되어 조류와 식물성 플랑크톤이 급격히 증식하는 현상이다. 진행 과정은 다음 열 단계로 정리된다.

1. 다량의 **인과 질소 유입**
2. 조류와 기타 수생식물의 대폭적 성장
3. 광합성 산물 증가로 영양소 증가
4. 식물생장 더욱 촉진
5. 식물플랑크톤이 따뜻한 **상층부에 밀집**(진초록색)
6. 조류·유기물 잔해 다량이 **바닥으로 침강**
7. 바닥에 서식하는 **세균이 죽은 유기물을 분해**
8. 세균 활동에 의한 **바닥의 산소 고갈**
9. **저서종의 수 감소**
10. 극단적인 경우 산소 고갈로 **무척추동물과 어류의 집단폐사**

담수 생태계에서는 **인(P)이 흔히 제한요인(limiting factor)**으로 작용하기 때문에, 인의 유입 증가가 부영양화의 결정적 방아쇠가 된다.

**관련 문제**: (2023-3-14)

#### 6.2.2 부영양화의 피해 — 투명도는 감소한다

부영양화의 대표적 피해는 **악취 발생, 수중생태계 파괴, 용존산소량 고갈에 따른 어패류 폐사**이다.

여기서 출제 함정은 **"조류(algae)의 이상번식에 의한 투명도 증가"**이다. 방향이 정반대다. 수면을 덮은 조류는 **햇빛을 차단하고 부유 물질을 증가**시켜 물의 **투명도를 크게 저하**시킨다. 부영양화된 수계가 탁하고 진초록색을 띠는 것이 바로 이 때문이다.

**관련 문제**: (2022-1-17)

#### 6.2.3 남조류 대발생 조건

부영양화 초기에 남조류(cyanobacteria, *Microcystis*·*Anabaena* 등)가 대량 발생하는 조건은 수질·기상·수리 세 범주로 정리된다.

| 구분 | 주요항목 | 주요내용 |
|------|---------|---------|
| **수질** | 영양염류 **질소(N)·인(P)** | 남조류 성장에 필수적인 영양염류가 충분히 공급되면 급격히 번식. 대부분의 수체에서 질소 농도가 상대적으로 높고 남조류 일부는 질소를 대기로부터 고정하므로 일반적으로 **인(P) 농도가 성장 제한인자**로 작용 |
| **수질** | 유기물(C) 농도 | 유기물의 농도 역시 제한인자로 작용할 수 있음 |
| **수질** | 미량원소 | **Fe** 등 미량원소는 광합성·질소고정·에너지 이동 등에 필수. 부족 시 성장 저해 |
| **기상** | 빛(일사량) | **일사량의 증가**(맑은 날의 지속)는 광합성을 통한 성장에 유리 |
| **기상** | 수온 | **수온 상승**(25℃ 이상)은 남조류 성장에 유리한 조건 형성 |
| **수리** | 유속(체류시간) | **유속의 증가는 수직혼합을 촉진하여 남조류의 표층번성을 막고**, 흐름이 빨라지면 유하시간이 짧아져 조류가 성장할 시간을 단축시켜 **조류 발생이 저감**됨 |

따라서 **"수량(유량) 증가"**와 **"유속 증가"**는 남조류 발생 조건이 **아니라 억제 요인**이다. 수량이 증가하면 영양염류가 **희석**되고 체류시간이 짧아져 조류가 증식할 시간이 부족해진다. 실제로 녹조는 **강우가 적고 유량이 감소하여 정체수역이 형성되는 여름철 갈수기**에 심하게 발생한다.

실무에서 조류경보 발령 시 **댐 방류량을 늘려 유속을 높이는 플러싱(flushing) 대책**을 시행하는 것이 바로 이 원리를 이용한 것이다.

**관련 문제**: (2023-3-14), (2024-3-18)

#### 6.2.4 부영양화 저감 대책

부영양화 저감의 핵심은 단 하나, **영양염류 유입을 줄이는 것**이다. 대책은 오염원 유형에 따라 나뉜다.

| 구분 | 대책 |
|------|------|
| **점오염원** | 하수 및 축산폐수 관리 강화(고도처리 도입, 방류수 총인 기준 강화) |
| **비점오염원** | 비료 및 농약 사용 절감, 농경지 유출 저감 |
| **차단·완충** | **식생완충대(buffer zone) 조성** — 수변 식생이 유입 영양염을 흡수·여과 |
| **수리적 대책** | 방류량 증대를 통한 플러싱, 체류시간 단축 |

**"영양염류 공급을 증가시켜 수생태 생산성을 높인다"**는 것은 저감 대책이 될 수 없다. 영양염류를 오히려 증가시키면 **녹조·적조가 심화**되어 표층에서 광차단이 일어나고, 조류 사체 분해 시 **용존산소가 고갈(빈산소층 형성)**되어 어패류가 폐사한다.

한편 하천의 **코리더(수변 식생대)**는 수온 조절, 수질 정화, 생물 서식처 제공 등 다양한 생태적 기능을 수행한다. 특히 주변 지역에서 유입되는 **질소(NO₃⁻)와 인(PO₄³⁻) 같은 영양염류를 식생이 흡수하고 토양이 여과**하여 **하천의 부영양화를 억제**하는 완충 지대 역할을 한다. 따라서 "하천 코리더의 기능"으로 **"부영양화 증대"**를 드는 것은 정반대의 서술이다.

**관련 문제**: (2022-1-20), (2025-1-10)

#### 6.2.5 하천 수변림의 생태적 기능

하천주변을 따라 형성된 숲 통로, 즉 **수변림(riparian forest)**은 물고기의 서식에 중요한 요소가 된다. 그 기능은 네 가지로 정리된다.

- **수온 조절**: 수면에 그늘을 만들어 수온 상승을 억제하고 용존산소를 유지
- **먹이 공급**: 낙엽·낙지가 수생 무척추동물의 먹이원(**allochthonous input**, 외래성 유기물 유입)이 됨
- **서식처 제공**: 뿌리와 하안 구조가 어류의 은신처·산란처를 제공
- **여과**: 육상에서 유입되는 토사와 영양염류를 여과하여 **오히려 부영양화를 억제**

따라서 **"하천주변 식생이 발달하게 되면 어류의 서식이 어렵고 부유물이 증가하여 하천부영양화의 원인이 될 수 있다"**는 서술은 **정반대**다.

수변식생의 여과 기능을 담당하는 **식생여과대**에서는 **미생물과 식물이 질소나 인 등 영양소를 흡수하고 농약을 여과**시킨다. 또한 수로를 따라 흐르는 지표수나 지하수는 물을 이동시키면서 물과 수변의 서식처를 유지하며, 하천통로의 **장벽 기능 발휘는 통로의 형태와 동물의 행동에 의해서 좌우**된다.

**관련 문제**: (2025-3-3)

### 6.3 하천 조사 — 차수와 어류 분포 요인

#### 6.3.1 스트랄러 하천 차수

**하천 차수(stream order)**는 **스트랄러(Strahler)** 방식으로 결정하며, 세 가지 규칙만 알면 된다.

**규칙 1 (출발점)** — 지류가 없는 하천의 시작점, 즉 산지에서 발원하거나 더 작은 지류와 합류하지 않은 가장 작은 하천을 **1차 하천**으로 정의한다. 지도에서 가장 얇은 실선 같은 작은 물줄기가 모두 1차 하천이다.

**규칙 2 (같은 차수끼리 합류)** — 같은 차수의 두 하천이 만나면 합류된 하천은 **한 단계 높은 차수**가 된다. 1차 + 1차 = **2차**, 2차 + 2차 = **3차**.

**규칙 3 (다른 차수끼리 합류)** — 서로 다른 차수의 하천이 만나면 합류된 하천은 **더 높은 쪽의 차수를 그대로 유지**한다. 1차 + 2차 = **2차**, 2차 + 3차 = **3차**.

이 규칙을 하천망 전체에 반복 적용하여 본류까지 확장하면, 최종적으로 유역 내 가장 높은 차수가 본류 차수가 된다.

**[기출 대입 ①]** 그림에서 ㄱ은 1차 하천 2개가 만났으므로 **2차**, ㄴ은 지류가 없는 시작점이므로 **1차**, ㄷ은 **5차 하천과 1차 하천이 만난 후의 구간**이므로 규칙 3에 따라 높은 쪽인 **5차**가 유지된다.

**[기출 대입 ②]** ㄱ은 1차 하천 두 개가 만난 지점이므로 **2차**, ㄴ도 동일하게 **2차**, ㄷ은 같은 차수가 만나 **3차**, ㄹ은 최종 본류로 **4차**가 된다.

가장 자주 틀리는 지점은 **규칙 3**이다. 큰 하천에 작은 지류가 합류해도 **차수는 올라가지 않는다**. 오직 같은 차수끼리 만날 때만 +1이 된다는 점을 반드시 붙잡아야 한다.

하천차수는 유역의 규모와 하천 발달 정도를 나타내는 지표로, **차수가 높을수록 유역면적·유량이 크고 하도 경사는 완만**해진다. 생태복원에서는 차수별로 서식 환경과 적용 공법이 달라지므로 기본 개념으로 중요하다.

**관련 문제**: (2022-2-19), (2025-3-1)

#### 6.3.2 수생태계 어류 분포의 영향 요인

어류의 분포를 결정하는 핵심 물리·화학적 요인은 **수온, 용존산소(DO), 수심, 유속, 하상재질, 탁도, pH, 염분** 등이다.

| 요인 | 작용 기작 |
|------|----------|
| **수온** | 변온동물인 어류의 **대사속도와 산란시기를 직접 지배**. 냉수성 어종(열목어·산천어)과 온수성 어종(붕어·잉어)의 서식 구간을 가름 |
| **용존산소** | 호흡에 직결. 냉수성 어종은 **7mg/L 이상**, 오염내성종은 **3mg/L 내외**에서도 생존 |
| **수심** | 빛의 투과, 수온 성층, 은신처 제공과 연결되어 **여울-소(pool) 구조**에 따른 어종 분화를 만듦 |

반면 **기압**은 어류분포의 주요 영향요인으로 보지 않는다. **수심 10m마다 1기압씩 증가하는 수압**에 비해 **대기압 변화(보통 ±수십 hPa)는 무시할 수 있는 수준**이기 때문이다. 수중 생물에게 대기압 변동이 미치는 영향은 극히 작다.

**관련 문제**: (2025-2-6)

#### 6.3.3 기수역의 환경 특성

**기수(汽水, brackish water)**는 담수와 해수가 섞여 **염분 농도가 약 0.5~30‰** 범위에 놓이는 물을 말한다. 하천이 바다로 흘러드는 **하구역(estuary)**이나 동해안의 **석호(경포호, 화진포, 송지호 등)**에서 전형적으로 나타난다. 참고로 **담수는 염분 0.5‰ 미만, 해수는 약 35‰ 내외**이다.

기수역은 조석과 담수 유입에 따라 **염분이 시시각각 변하는 환경**이므로, 서식 생물은 넓은 염분 변화를 견디는 **광염성(廣鹽性, euryhaline) 종**이 주를 이룬다. 뱀장어·연어처럼 담수와 해수를 오가는 **회유성 어류의 통과 경로**이자, 영양염이 풍부하여 어류의 **산란·보육장(nursery ground)** 기능을 하는 **생산성이 매우 높은 생태계**다. 갈대·칠면초 등의 염생식물 군락과 갯벌이 발달하며, **하구둑 건설로 담수와 해수의 소통이 차단되면 기수 생태계가 급격히 훼손**된다.

[ **기수역 규조류의 특징** ]

기수역에 서식하는 규조류는 **생물 크기가 대체로 작고 서식종의 종 수가 적다**. 이유는 기수역이 담수와 해수가 만나는 **전이 지대로서 염분 농도의 변화가 매우 심해 환경적 스트레스가 높은** 지역이기 때문이다. 불안정한 환경에 적응하여 생존할 수 있는 종이 제한적이므로 **종 다양성이 낮으며**, 급격한 환경 변화에 대응하기 위해 **크기도 대체로 작게** 나타난다.

**관련 문제**: (2022-1-7), (2024-2-15)

### 6.4 토양 환경 조사

#### 6.4.1 토양수분의 구분

토양수분은 **토양입자에 붙잡혀 있는 힘(토양수분장력)의 크기**에 따라 세 가지로 구분된다. 이 구분이 그대로 출제되므로 각각의 정의와 특징을 정확히 잡아야 한다.

| 구분 | 설명 | 특징 |
|------|------|------|
| **흡습수**(Hygroscopic Water) | 대기로부터 토양에 흡착되는 물 | • 이동하지 못함<br>• **식물이 흡수할 수 없음** |
| **모세관수**(Capillary Water) | 토양공극 중 모세관 공극에 존재하는 물 | • **식물이 흡수할 수 있음**<br>• 토양의 모세관 공극률이 높을수록 많아짐 |
| **중력수**(Gravitational Water) | **자유수(Free Water)**. 중력의 작용에 의하여 토양공극에서 쉽게 제거되는 물 | • 양질사토는 강수 후 **1일 이내**에 제거됨<br>• 식양토는 강수 후 **4일 정도** 후에 제거됨 |

**[출제 지문 해독]** "중력의 작용에 의하여 토양공극에서 쉽게 제거되는 물 / 자유수라고도 하며, 많은 물이 유입되어 토양이 포화상태로 되었을 때 존재할 수 있고, 대부분 **표면장력이 매우 약하게 작용하는 대공극에 존재** / 포화상태에서 일시적으로 토양에 존재하는 물이므로 식물이 일부 흡수 이용할 수 있지만 **작물의 생육기간 동안 지속적으로 이용될 수 있는 물은 아니다**" → **중력수**

중력수는 토양수분장력이 약 **1/3기압(pF 2.5) 이하**로 매우 약하게 붙잡혀 있어 중력에 의해 아래로 빠져나간다. 중력수가 모두 빠져나간 직후의 수분 상태가 바로 **포장용수량**이다.

여기서 함정은 **포장용수**를 물의 종류로 착각하는 것이다. **포장용수(량)는 물의 종류가 아니라 수분 상태(함량)를 가리키는 용어**이므로 흡습수·모세관수·중력수와 같은 층위에 놓을 수 없다.

**관련 문제**: (2023-1-4)

#### 6.4.2 토양수분 항수 — 포장용수량과 위조점

토양수분의 양적 기준점을 **수분항수**라 하며, 다음 네 가지가 핵심이다.

| 용어 | 정의 | 수분장력 |
|------|------|---------|
| **포화**(Saturation) | 모든 공극이 물로 채워진 상태. 산소가 부족해 **뿌리 호흡이 저해**됨 | 0 |
| **포장용수량**(Field Capacity) | 강우나 관개 후 **중력수가 모두 빠져나가고 남은 수분량**. 대공극은 공기로 채워져 뿌리 호흡이 원활하면서도 소공극에는 물이 남아 있어 **식물의 생육에 가장 적합한 상태** | 약 **1/3기압(pF 2.5)** |
| **위조점**(Wilting Point) | 식물이 물을 흡수하지 못해 **영구적으로 시드는 지점** | 약 **15기압(pF 4.2)** |
| **유효수분**(Plant-Available Water) | 토양저장 수분 중 식물이 실제로 이용 가능한 수분. **포장용수량과 위조점 사이의 수분량** | 1/3~15기압 구간 |

**[출제 지문 해독]** "**대공극의 물이 빠져나가 뿌리의 호흡을 좋게 하면서도 소공극에는 식물이 이용할 수 있는 충분한 양의 물이 아직 있는 상태**이므로 식물이 생육하기에 가장 좋은 수분 조건" → **포장용수량**

[ **토성별 수분특성 (단위 %)** ]

| 구분 | 포장용수량 | 위조점 수분함량 | 유효 수분함량 |
|------|-----------|----------------|--------------|
| 사양토 | 11.3 | 3.4 | **7.9** |
| 양토 | 18.1 | 6.8 | **11.3** |
| 미사질양토 | 19.8 | 7.9 | **11.9** |
| 식양토 | 21.5 | 10.2 | **11.3** |
| 식토 | 22.3 | 14.1 | **8.2** |

이 표가 말해주는 두 가지 결론이 있다.

첫째, **포장용수량과 위조점은 점토 함량이 높을수록 함께 증가**한다(사양토 11.3 → 식토 22.3). 점토는 표면적이 넓어 물을 많이 붙잡기 때문이다.

둘째, 그런데 **유효수분함량은 식토(8.2)나 사양토(7.9) 같은 극단적인 토성보다 양토(11.3)·미사질양토(11.9) 계열에서 가장 크다**. 식토는 물을 많이 머금지만 그만큼 강하게 붙잡아 위조점도 높아지므로 실제 식물이 쓸 수 있는 구간은 좁아진다. 반대로 사토는 애초에 보유량 자체가 적다. **중간 토성이 최적**이라는 것이 핵심이다.

[ **수분퍼텐셜과 식물 생장** ]

수분퍼텐셜에 따른 식물생장속도 곡선은 **종 모양(bell-shaped)**을 나타낸다. **포화 상태에서는 산소 부족으로 생장이 억제**되고, **포장용수량 부근에서 생장속도가 최대**에 이르며, **위조점 쪽으로 갈수록 물 부족으로 급격히 감소**한다. 즉 **식물 생장은 물이 많을수록 좋은 것이 아니라 포장용수량 부근에서 최적**이 된다는 점이 핵심이다.

**관련 문제**: (2023-1-5)

#### 6.4.3 토양 내 무기영양소의 이동성

토양 및 식물체 내에서 원소의 **이동성(mobility)**은 다음과 같이 구분된다.

- **이동이 쉬운 원소**: 질소(N), 인(P), **칼륨(K)**, 마그네슘(Mg)
- **이동이 쉽지 않은 원소**: 칼슘(Ca), 철(Fe), 붕소(B), 황(S), 망간(Mn)

**칼륨(K⁺)**은 1가 양이온으로 **수화반경이 작고 토양교질에 대한 흡착력이 상대적으로 약해** 토양용액 속에서 자유롭게 이동하며, 식물체 내에서도 **체관을 통해 재전류(retranslocation)가 활발**하다.

이동성의 차이는 **결핍 증상이 나타나는 위치**로 곧바로 확인된다.

| 이동성 | 결핍 증상 발현 위치 | 이유 |
|--------|-------------------|------|
| **이동 쉬움**(N·P·K·Mg) | **오래된 아래쪽 잎** | 오래된 잎의 양분이 새 잎으로 이동해 감 |
| **이동 어려움**(Ca·Fe·B) | **생장점·어린 잎** | 한 번 자리 잡으면 재이동이 거의 없음 |

칼슘은 **세포벽의 펙틴산칼슘 형태로 고정**되어 재이동이 거의 없으므로 결핍 증상이 생장점과 어린 잎에서 먼저 나타난다.

**관련 문제**: (2024-1-8)

#### 6.4.4 토양 질소의 존재 형태

식물은 대기의 약 **78~80%**를 차지하는 질소를 직접 이용할 수 없다. **삼중결합(N≡N)**으로 매우 안정한 분자질소(N₂) 형태이며 결합에너지가 약 **941 kJ/mol**에 달하기 때문이다. 이 결합을 끊으려면 **니트로게나아제(nitrogenase) 효소**나 번개·공업적 **하버-보슈법** 같은 고에너지 과정이 필요하다.

고정된 질소는 **토양입자에 흡착·보유**되며, 식물은 **토양입자 속의 질소**를 오직 **두 가지 무기 이온 형태**로만 뿌리를 통해 흡수한다.

| 형태 | 성질 | 토양 내 거동 |
|------|------|-------------|
| **암모늄태 질소(NH₄⁺)** | **양이온** | 토양교질(음전하)에 **흡착되어 잘 용탈되지 않음** |
| **질산태 질소(NO₃⁻)** | **음이온** | 토양교질에 흡착되지 않아 **강우 시 쉽게 용탈**되며, **지하수 오염의 원인** |

관련 전환 과정은 두 가지다.

- **질산화작용(nitrification)**: 암모늄이 아질산(NO₂⁻)을 거쳐 질산으로 **산화**되는 과정
- **탈질작용(denitrification)**: 질산이 다시 N₂로 **환원**되어 대기로 돌아가는 과정. **NO₃⁻ → NO₂⁻ → NO → N₂O → N₂** 순으로 진행

**탈질작용은 산소농도가 낮고(혐기적) 질산염의 농도가 높은** 특별한 환경조건에서 일어난다. "산소농도가 높고"라는 서술은 틀린 것이다. *Pseudomonas*, *Paracoccus* 등 통성 혐기성 세균이 산소가 부족할 때 산소 대신 질산이온을 최종 전자수용체로 사용하는 호흡이기 때문이다. 산소가 충분하면 세균은 에너지 효율이 높은 산소호흡을 택하므로 탈질이 억제된다. **침수된 논토양, 습지, 하수처리장의 무산소조**가 대표적 탈질 환경이며, 탈질 속도는 **pH·알칼리도·용존산소·유기탄소원(전자공여체) 농도·온도**의 영향을 받는다.

**관련 문제**: (2023-1-3), (2024-1-6), (2024-1-7), (2025-2-2)

### 6.5 원격탐사(Remote Sensing)

#### 6.5.1 원격탐사의 정의와 원리

**원격탐사(Remote Sensing)**는 **물체로부터 반사 또는 방출되는 전자기파를 이용하여 물체의 성분·종류·상태 등을 조사하는 기술**이다. 달리 표현하면, 센서를 이용해 지표·지상·지하·대기권 및 우주공간의 대상물에서 **반사나 방사되는 전자기파를 감지**하고 이에 대한 정보를 획득·해석하는 기법이다.

핵심 원리는 **"모든 물체는 종류 및 환경조건이 다르면 각기 다른 전자파의 반사 및 방사 특성을 갖는다"**는 **전자파 스펙트럼 특성**이다. 물체마다 파장대별 반사 특성이 다른데 이를 **분광반사특성곡선(spectral signature)**이라 한다.

[ **기술 발전 단계** ]

- **1970년대 이전**: 비행기 등에서 찍은 **아날로그 형태의 사진**(항공사진 촬영)이 중심
- **1970년대 이후**: **플랫폼**(원격탐사용 센서를 탑재한 위성이나 비행기)에서 **주기적으로 관측한 디지털 정보**를 분석. 인공위성에 **다중분광 센서(multispectral sensor)**를 탑재하여 정량적 분석 수행

[ **센서의 구분** ]

| 구분 | 원리 | 사례 | 특징 |
|------|------|------|------|
| **능동형**(active) | 센서가 **스스로 전자파를 발사**해 되돌아오는 신호를 측정 | SAR(합성개구레이더), LiDAR | **야간이나 구름이 낀 날씨에도 관측 가능** |
| **수동형**(passive) | **태양복사의 반사**를 측정 | 광학 카메라 | 주간·맑은 날씨에 한정 |

RADARSAT의 **SAR(합성개구레이더)**가 능동형의 대표 사례로, 기상 조건에 구애받지 않는다는 결정적 장점이 있다. **라이다(LiDAR)**는 **전자파가 대상에 부딪힌 뒤 되돌아오는 반사파를 측정하여 대상을 탐지하고 그 방향·거리·속도 등을 파악하는 정보시스템**으로, 레이저 펄스의 왕복시간을 측정해 지형·수관층의 3차원 좌표를 얻는 능동형 장비다.

**관련 문제**: (2023-1-16), (2024-2-14), (2024-3-16), (2025-3-15)

#### 6.5.2 원격탐사의 장점

원격탐사의 대표적 장점은 네 가지이며, 그중 셋이 출제에 직접 등장한다.

| 장점 | 내용 |
|------|------|
| **광역성** | 한 장면에 **수십~수백 km**에 이르는 넓은 지역을 동시에 담을 수 있다 |
| **동시성** | 넓은 지역의 정보를 **같은 시각에 한꺼번에** 취득해 시간차에 따른 오차가 없다 |
| **주기성** | 위성이 일정 궤도를 반복 통과하므로 같은 지역을 **일정 주기로 반복 관측**해 시계열 변화 분석이 가능하다 |
| **접근성** | 사람이 직접 가기 어려운 **오지·산악·해양·분쟁지역**도 관측 가능하다 |

출제 함정은 **"단발성"**이다. 단발성은 한 번만 관측하고 끝난다는 뜻이므로, **반복·주기적 관측이 가능하다는 원격탐사의 핵심 장점(주기성)과 정면으로 모순**된다. 따라서 장점이 아니다.

이러한 장점 덕분에 인공위성 원격탐사는 **지구온난화에 따른 삼림의 황폐화, 사막화 증가, 농사작황과 농작물 병충해 정보, 해수면 온도변화, 도시 열섬 현상** 등 지구의 환경정보를 **광역적·장기적 시계열 데이터**로 확보할 수 있어 기후변화 연구 및 환경 관리에 핵심 자료를 제공한다.

**관련 문제**: (2023-2-8), (2025-3-15)

#### 6.5.3 원격탐사 위성의 종류 — 제원표

위성 제원표는 **동일한 표가 2회 이상 출제**된 최빈출 항목이다. 특히 **"최초"**와 **"해상도"** 두 축이 함정으로 쓰인다.

| 위성 | 국가 | 특징 |
|------|------|------|
| **LANDSAT** | 미국 | **최초의 원격탐사위성**. LANDSAT-1(발사 당시 명칭 ERTS-1)이 **1972년** 발사된 최초의 지구관측 위성 |
| **IKONOS** | 미국 | 상업용 위성으로 **세계 최초로 1m급 고해상도** 제공(1999년 발사). 한반도지역 송신, **대축척 지도 제작 가능** |
| **Quick Bird** | 미국 | 상업용 **최고해상도인 60cm급** 영상 제공. **미국 본토 외 지역 수신 불가능** |
| **KOMPSAT** | 한국 | **우리나라 최초 실용 원격탐사위성**. 지구관측, 해양관측, 과학실험 및 우주데이터 수집 |
| **RADARSAT** | 캐나다 | **레이더 센서 SAR 탑재**(능동형) |
| **SPOT** | 프랑스 | **LANDSAT 위성보다 해상도가 높음** |
| **IRS** | 인도 | 민간 지구 관측 위성(**1988년** 발사) |

[ **반복 출제되는 두 함정** ]

**함정 ①** — "**IKONOS** 위성은 지구관측을 위해 1972년 발사된 최초의 원격탐사위성" → **틀림**. 1972년 발사된 최초의 지구관측 원격탐사위성은 IKONOS가 아니라 **LANDSAT-1**이다. IKONOS는 **1999년**에 발사된 상업용 고해상도 위성으로, 세계 최초로 **1m급 해상도**의 위성영상을 민간에 제공하여 대축척 지도 제작을 가능하게 한 위성이다.

**함정 ②** — "**IRS**(Indian Remote Sensing Satellite) 위성은 1972년에 발사된 최초의 지구관측 위성" → **틀림**. 최초의 지구관측 위성은 **LANDSAT-1(1972년)**이며, IRS 위성은 인도가 **1988년**에 발사한 원격탐사위성이다.

두 함정 모두 **"1972년 최초 = LANDSAT"**이라는 한 문장만 확실히 붙잡으면 동시에 해결된다. 다른 위성 이름에 1972년이 붙어 있으면 무조건 오답이다.

**관련 문제**: (2023-1-16), (2025-3-15)

#### 6.5.4 알베도와 분광반사율

[ **알베도의 정의** ]

**알베도(albedo)**는 **물체가 빛을 받았을 때 표면에 의해 도달한 복사조도와 반사된 복사조도의 비율**이다. 즉 지표면이나 물체에 입사한 태양복사 에너지 중 반사되어 되돌아가는 비율을 **0~1(또는 %)** 값으로 나타낸 것이다.

값이 **클수록 밝고 반사가 많아 표면이 덜 데워지며**, 값이 **작을수록 흡수가 많아 표면 온도가 올라간다**. **지구 전체의 평균 알베도는 약 0.3**이다. 도시의 아스팔트·건물처럼 **알베도가 낮은 면적이 늘어나는 것이 도시열섬 현상의 주요 원인** 중 하나다.

혼동을 유도하는 인접 용어들과 함께 정리하면 다음과 같다.

| 용어 | 정의 |
|------|------|
| **알베도** | 도달한 복사조도와 **반사된 복사조도의 비율** |
| **전자기파** | 전자기장의 흐름에서 발생하는 일종의 **전자기 에너지** |
| **원격탐사** | 물체로부터 반사 또는 방출되는 전자기파를 이용하여 **물체의 성분·종류·상태 등을 조사하는 기술** |
| **라이다(LIDAR)** | 전자파가 대상에 부딪힌 뒤 되돌아오는 **반사파를 측정**하여 대상을 탐지하고 그 **방향·거리·속도** 등을 파악하는 정보시스템 |

[ **지표 종류별 알베도** ]

| 지표의 종류 | 지표면 알베도 |
|------------|--------------|
| 신적설 | **0.6~0.9** |
| 융설 | 0.4~0.7 |
| 사막 | 0.3~0.5 |
| **토양** | **0.05~0.3** |
| 툰드라 | 0.15~0.35 |
| 초지 | 0.15~0.25 |
| 산림 | 0.05~0.2 |
| **물** | **0.05~0.1** |

[ **분광반사율 순서 — 토양 > 식물 > 물** ]

위 표에서 **토양(0.05~0.3)의 상한이 가장 높고**, 식물(초지 0.15~0.25 / 산림 0.05~0.2)이 그다음이며, **물(0.05~0.1)이 가장 낮다**. 따라서 분광반사율이 큰 순서는 **토양 > 식물 > 물**이다.

각각의 이유는 다음과 같다.

- **물**: 입사한 태양복사의 대부분을 **흡수하거나 수면 아래로 투과**시키고 반사는 매우 적어 원격탐사 영상에서 **어둡게** 나타난다.
- **토양**: 나지·건조한 토양은 표면이 밝고 거칠어 **가시광~근적외 전 영역에서 비교적 높은 반사율**을 보인다.
- **식물**: 파장에 따라 반사 특성이 크게 달라, **가시광 적색 영역은 엽록소가 흡수하여 낮지만 근적외 영역에서는 엽육조직의 산란으로 급격히 높아진다**. 이 급상승 구간을 **red edge**라 한다.

**관련 문제**: (2024-2-13), (2024-2-14)

#### 6.5.5 NDVI — 정규식생지수

식생의 red edge 특성, 즉 **근적외선(NIR)에서 강한 반사**를 보이고 **적색광(Red)에서 강한 흡수**를 보이는 차이를 이용한 것이 **정규식생지수(NDVI)**다.

**NDVI = (NIR − Red) / (NIR + Red)**

값의 범위는 **−1 ~ +1**이며, 식생이 무성하고 활력이 높을수록 NIR과 Red의 차이가 커져 값이 **+1에 가까워진다**. 반대로 물은 NIR을 거의 반사하지 않으므로 **음수**가 되고, 나지·구조물은 두 파장대의 반사가 비슷해 **0 부근**의 값을 갖는다.

NDVI는 **식생 활력도와 피복 분석**에 널리 쓰이며, 시계열로 축적하면 **가뭄 모니터링, 산림 황폐화 추적, 생물계절(phenology) 분석**이 가능하다.

**관련 문제**: (2024-3-16)

### 6.6 지리정보시스템(GIS)

#### 6.6.1 GIS의 정의

**지리정보시스템(GIS, Geographic Information System)**은 **지역에서 수집한 각종 지리정보를 수치화하여 컴퓨터에 입력·저장·처리하고, 이를 사용자의 요구에 따라 다양한 방법으로 분석·종합하여 제공하는 시스템**이다. 달리 표현하면 **각종 지리정보들을 데이터베이스화하고 공간정보에 속성정보를 덧붙여서 만드는 기술**이다.

정의를 확장하면 다음과 같다.

- 특정 목적을 가지고 **공간자료를 저장하고 추출하며, 이를 변환하여 보여주거나 분석하는** 강력한 도구
- **지리적으로 참조 가능한 모든 형태의 정보**를 효과적으로 수집·저장·갱신·조정·분석·표현할 수 있도록 설계된 컴퓨터시스템
- 공간상 위치를 점유하는 **지리자료와 이에 관련된 속성자료를 통합 처리**

인접 개념과의 관계를 정리하면, **원격탐사(RS)**는 인공위성·항공기 센서로 지표면에 접촉하지 않고 정보를 취득하는 **자료 수집 기술**로 **GIS의 주요 입력자료원**이 된다. **데이터베이스**는 자료를 체계적으로 저장·관리하는 일반적 개념으로 **공간분석 기능은 포함하지 않는다**.

**관련 문제**: (2024-1-17)

#### 6.6.2 GIS의 구성요소

GIS의 구성요소는 **하드웨어·소프트웨어·데이터베이스·인력**의 4요소(또는 여기에 방법(method)을 더한 5요소)로 설명된다.

| hardware | software | database | human power |
|---|---|---|---|
| 중앙처리장치, 기억장치, 입력장치, 출력장치 | OS, graphic software, **DBMS**(database management system), mapping and analysis software | **spatial database**, **attribute database** | GIS 이용 시 필요한 인력 |

출제된 정답 조합은 **"작업자, 데이터, 하드웨어, 소프트웨어"**이다. 오답이 만들어지는 원리를 알면 판별이 쉽다. **중앙처리장치는 하드웨어의 하위 요소**이고, **공간정보·속성정보는 데이터(database)의 하위 요소**이므로 **동일 위계의 구성요소로 나열할 수 없다**. 즉 상위 개념과 하위 개념이 뒤섞인 보기가 오답이다.

[ **DBMS의 데이터 모델** ]

- **계층형 데이터**: 상위항목이 있고, 구체화한 하위항목이 존재
- **네트워크형 데이터**: 한 데이터를 다른 데이터와 공통부분으로 연결
- **관계형 데이터**: keyword 몇 개를 통해 모든 데이터를 연결

**관련 문제**: (2024-2-1)

#### 6.6.3 공간정보와 속성정보

GIS 자료는 크게 **공간데이터**와 **속성데이터**로 구분된다. 이 둘의 정의가 **서로 뒤바뀐 형태로 출제**되므로 정확히 구분해야 한다.

| 구분 | 정의 | 구성 |
|------|------|------|
| **공간정보**(spatial data) | **위치와 형태**를 나타내는 정보 | **점(point)·선(line)·면(polygon)** |
| **속성정보**(attribute data) | 그 공간객체가 **무엇인지 설명**하는 정보 | **정성적 데이터**(토지이용 유형, 수종명 등 — 숫자정보 없음, 통계적 분석 불가능) / **정량적 데이터**(면적, 수고, 인구수 등 — 숫자정보 있음, 통계적 분석 가능) |

**[함정 ①]** "GIS **공간정보**는 정성적 데이터와 정량적 데이터로 구성되며, **속성정보**는 점·선·면으로 구성된다" → **틀림**. 두 정의가 **서로 뒤바뀌어 있다**. 점·선·면은 공간정보, 정성/정량 구분은 속성정보다.

**[함정 ②]** "GIS 자료는 크게 공간데이터와 속성데이터로 구분되며 **속성데이터**는 다시 벡터데이터와 래스터데이터로 구분된다" → **틀림**. 벡터/래스터로 구분되는 것은 속성데이터가 아니라 **공간데이터**다. 공간데이터는 **위치를 표현하는 방식**에 따라 벡터 구조와 래스터 구조로 나뉜다.

두 함정 모두 **"점·선·면 = 공간, 그것이 무엇인지 = 속성, 벡터/래스터 = 공간의 표현 방식"**이라는 삼단 정리로 해결된다.

**관련 문제**: (2023-1-15), (2024-2-2)

#### 6.6.4 벡터 데이터와 래스터 데이터

| 데이터 | **Raster Data** | **Vector Data** |
|--------|-----------------|-----------------|
| **내용** | **Cell이나 Grid Matrix**로 표현<br>**확대하면 깨짐** | **점, 선, 면**을 이용해서 표현<br>**확대해도 깨지지 않음** |
| **사례** | **.jpeg, .png, .gif** | **.pdf, .autocad, .svg** |
| **장점** | 분석, 모델링 쉬움 | 복잡하고 정교한 작업 가능<br>고수준 분석 가능<br>**상대적 용량 작음** |
| **단점** | 낮은 수준의 분석만 가능<br>낮은 해상도<br>**상대적 데이터크기가 큼** | 상대적인 고수준 기술 요구<br>비용이 비쌈 |

[ **벡터 데이터의 장단점 상세** ]

| 구분 | 내용 |
|------|------|
| **장점** | • **정확한 위치 표현 가능 — 해상도 제한 없음**<br>• **속성 정보 저장 및 관리 용이 — 데이터베이스 연계 가능**, 벡터 데이터 간 속성정보 결합 가능<br>• **공간 분석(네트워크 분석, 중첩 분석 등) 가능**<br>• **파일 크기가 상대적으로 작음** (특히 단순한 객체일 경우) |
| **단점** | • **복잡한 형상 처리 시 연산 부담 증가**<br>• 곡선 표현이 어려울 수 있음<br>• 래스터에 비해 **자연적 현상(토양분포, 기온변화 등) 표현이 어려움** |

출제 함정은 **"파일크기가 상대적으로 크기 때문에 복잡한 형상 처리 시 연산 부담이 증가한다"**는 서술이다. **뒷부분(연산 부담 증가)은 맞지만 앞부분(파일크기가 크다)이 틀렸다**. 벡터는 점·선·면을 **좌표로 저장**하므로 **격자마다 값을 저장하는 래스터보다 파일 크기가 작은 것이 일반적**이다.

파일 확장자로 구분하는 요령도 유용하다. **사진 계열(.jpeg/.png/.gif)은 래스터**, **도면 계열(.pdf/.autocad/.svg)은 벡터**다.

**관련 문제**: (2023-1-15), (2024-2-2), (2025-1-11)

#### 6.6.5 GIS의 기능적 요소 처리순서

GIS의 기능적 요소는 자료를 수집하는 단계부터 최종 결과물을 생성하는 단계까지 **논리적인 흐름**을 가진다.

**자료 획득 → 자료 전처리 → 자료 관리 → 조정과 분석 → 결과 출력**

각 단계의 내용은 다음과 같다.

1. **자료 획득**: 가장 먼저 외부로부터 자료를 얻는 과정
2. **자료 전처리**: 수집된 자료를 시스템에 적합한 형태로 변환하는 과정
3. **자료 관리**: 가공된 자료를 데이터베이스 등에 저장하고 유지하는 단계
4. **조정과 분석**: 관리되는 데이터를 바탕으로 사용자의 목적에 맞게 분석을 수행
5. **결과 출력**: 분석된 데이터를 지도나 도표 형태로 시각화하여 전체 절차를 완료

순서를 기억하는 요령은 **"얻고 → 다듬고 → 쌓고 → 분석하고 → 내보낸다"**이다. 어떤 정보시스템이든 따르는 보편적 흐름이므로 상식적으로도 유도할 수 있다.

**관련 문제**: (2022-1-6)

#### 6.6.6 GIS의 장점과 응용분야

[ **장점** ]

**비용과 시간의 절약, 유지관리 용이, 수치기준의 표준화, 의사결정 지원**

[ **응용분야** ]

| 분야 | 활용 내용 |
|------|----------|
| 농업 | 곡물생산량 및 관개시스템 관리 |
| 마케팅 | 특정 위치에 따라 원하는 종류의 사업정보 관리 |
| 전기/가스 | 통합된 작업을 계획하고 설계 |
| **환경** | **생태계 연구, 오염영향 추적** |
| 산림 | 산림조건의 시각화 |
| 지질학 | 지질학적 구조나 토양 분석 |
| 수리수문 | 관개시스템·수로 등 분석, 유역관리 |
| 도시계획 | 토지이용계획 수립 |

생태복원 분야에서는 특히 **중첩분석(overlay), 완충구역 분석(buffer), 최적경로 분석, 경관지수 산정, 비오톱 지도 작성, 생태자연도 제작**에 폭넓게 활용된다. GIS의 핵심은 **서로 다른 주제도를 레이어로 쌓아 공간적 관계를 분석**하는 데 있으며, 도로·행정경계 등을 점·선·면으로 표현한 **Vector 레이어**와 토지이용·고도 등을 격자로 표현한 **Raster 레이어**를 여러 층으로 겹쳐 중첩분석을 수행한다.

**관련 문제**: (2024-1-17), (2024-2-1)

#### 6.6.7 좌표체계 — TM과 UTM

**우리나라 국가기본도는 TM(평면직각좌표계, Transverse Mercator)을 사용한다.**

| 구분 | **TM**(평면직각좌표계) | **UTM**(국제횡축메르카토르) |
|------|----------------------|--------------------------|
| 특징 | **측량지역에 좌표 원점을 정함**. 우리나라 국가기본도의 기본체계이며 **서부원점·중부원점·동부원점·동해원점의 4가지를 혼용**하여 사용 | 지구를 **경도 6도, 위도 8도 간격**으로 격자를 나누어 각 구역마다 고유번호와 설정된 원점이 있음 |

[ **우리나라 TM 원점** ]

TM 원점은 **위도 38°N**을 기준으로 경도에 따라 네 개로 나뉜다.

| 원점 | 경도 |
|------|------|
| 서부원점 | 125°E |
| 중부원점 | 127°E |
| 동부원점 | 129°E |
| 동해원점 | 131°E |

**UTM**은 전 지구를 **60개 종대(zone)**로 나눈 국제 표준체계로, 우리나라는 **51S·52S 구역**에 속한다.

[ **혼동하기 쉬운 인접 용어** ]

- **EPSG**: 좌표계 자체가 아니라 각 좌표계에 부여된 **식별코드 체계**(예: **EPSG:5186** 중부원점 TM, **EPSG:4326** WGS84)
- **WGS84**: **GPS가 사용하는 지구 전체 기준 측지계**

즉 "우리나라 국가기본도의 좌표체계"를 묻는 문제에서 EPSG는 코드 체계라 답이 될 수 없고, WGS84는 GPS용 전지구 측지계라 국가기본도의 투영좌표계가 아니다.

**관련 문제**: (2024-3-17)

### 핵심 키워드 요약

| 키워드 | 핵심 포인트 |
|--------|------------|
| 용존산소(DO) | 단위 **ppm(mg/L)**. 표수층 최고 → **수온약층에서 급격히 감소**(증가 ✕) → 심수층 소량 |
| 수온약층 | metalimnion. 상층 산소공급 차단 + 유기물 분해 소비 → **DO 급감(산소약층)** |
| 보상점·보상심도 | **광합성 산소발생량 = 호흡 산소소비량**인 수심. 위=생산 영역, 아래=소비 영역 |
| 영양생성대 | photic zone, 보상심도 **위**. **NPP > 0**. 식물플랑크톤·부착조류가 생산자 |
| 영양분해대 | aphotic/profundal zone. 동화작용 불가, **혐기성 분해 우세 → H₂S 축적** |
| 저층(benthic) | **유기물 축적 + 산소 고갈**. "광합성 유리·유기물 축적 없음"은 오답 |
| 내부파 | 밀도 다른 두 수층 경계 파동 → 수직혼합 → 저층 영양염 상층 공급 → 표층 생산 증가. **용승류는 별개**(에크만 수송) |
| 온난화 수생태 | 해수온 ↑, 해수면 ↑, **DO ↓**, **pH ↓(산성화)**. pH 증가는 오답 |
| 농도 단위 | ppm 10⁻⁶ / **ppb 10⁻⁹ = ng·g⁻¹·μg·kg⁻¹·μg·L⁻¹·mg·m⁻³** / ppt 10⁻¹² |
| 부영양화 피해 | 악취·생태계 파괴·DO 고갈 어패류 폐사. **투명도는 감소**(증가 ✕) |
| 남조류 발생조건 | N·P(**인이 제한인자**)·유기물·Fe / 일사량 ↑ / 수온 ↑(25℃ 이상) / **유속·수량 증가는 억제 요인** |
| 플러싱(flushing) | 댐 방류량 증대로 유속 ↑ → 체류시간 단축 → 조류 억제 |
| 부영양화 저감 | 점오염원(하수·축산폐수) 처리, 비점오염원(비료·농약) 저감, **식생완충대**. 영양염 증가는 ✕ |
| 하천 코리더 기능 | 수온조절·수질정화·서식처. NO₃⁻·PO₄³⁻ 흡수로 **부영양화 억제**(증대 ✕) |
| 수변림 기능 | 그늘로 수온 억제 / 낙엽=**allochthonous input** / 은신·산란처 / 토사·영양염 여과 |
| 하천 차수 규칙 | 지류 없는 최상류=1차 / **같은 차수 합류 → +1** / **다른 차수 합류 → 큰 쪽 유지** |
| 하천 차수 대입 | 1+1=2, 2+2=3, **5+1=5(유지)**. 최종 본류가 최고 차수 |
| 어류분포 요인 | 수온·DO·수심·유속·하상재질·탁도·pH·염분 ○ / **기압 ✕**(수압 대비 무시 수준) |
| DO 기준 | 냉수성 어종 **7mg/L 이상**, 오염내성종 **3mg/L 내외** |
| 기수(brackish) | 염분 **0.5~30‰**. 담수 0.5‰ 미만, 해수 35‰. 하구역·석호(경포호·화진포·송지호) |
| 기수 규조류 | 염분 변동 스트레스 → **크기 작고 종 수 적음** |
| 토양수분 3구분 | **흡습수**(흡수 불가) / **모세관수**(흡수 가능) / **중력수**(자유수, 대공극, 쉽게 제거) |
| 중력수 배수 | 양질사토 **1일 이내**, 식양토 **4일 정도** |
| 포장용수량 | 중력수 배수 후 남은 수분. **1/3기압(pF 2.5)**. **생육 최적 조건**. 물의 종류가 아닌 수분 상태 |
| 위조점 | 영구위조. **15기압(pF 4.2)** |
| 유효수분 | 포장용수량 − 위조점. **양토·미사질양토에서 최대**(11.3·11.9), 식토·사양토는 작음 |
| 양분 이동성 | 쉬움 **N·P·K·Mg**(결핍은 오래된 잎) / 어려움 **Ca·Fe·B·S·Mn**(결핍은 어린 잎) |
| 칼륨 이동성 | 1가 양이온, 수화반경 작고 흡착 약함, **체관 재전류 활발** |
| 질소 흡수 형태 | **NH₄⁺(양이온, 흡착돼 용탈 적음)** / **NO₃⁻(음이온, 용탈 쉬움·지하수 오염)** |
| 탈질작용 | **산소 낮고 질산염 높은 혐기 조건**. NO₃⁻→NO₂⁻→NO→N₂O→N₂ |
| 원격탐사 정의 | 반사·방출 **전자기파**로 물체 성분·종류·상태 조사. **분광반사특성곡선** |
| 능동형 vs 수동형 | 능동 = 스스로 발사(**SAR·LiDAR**, 야간·구름도 관측) / 수동 = 태양복사 반사(광학) |
| RS 장점 | **광역성·동시성·주기성·접근성**. **단발성은 장점 아님**(주기성과 모순) |
| LANDSAT | **1972년 발사 최초의 지구관측 위성**(ERTS-1). IKONOS·IRS에 1972년 붙으면 오답 |
| IKONOS | **1999년**, 세계 최초 **1m급** 상업 고해상도, 대축척 지도 제작 |
| Quick Bird | 상업용 최고해상도 **60cm급**, 미국 본토 외 수신 불가 |
| KOMPSAT / RADARSAT / SPOT / IRS | 한국 최초 실용 위성 / SAR 탑재(캐나다) / LANDSAT보다 고해상도(프랑스) / 인도 1988년 |
| 알베도 정의 | 도달 복사조도 대비 **반사 복사조도의 비율**. 지구 평균 **약 0.3** |
| 알베도 값 | 신적설 0.6~0.9 > 사막 0.3~0.5 > **토양 0.05~0.3** > 초지 0.15~0.25 > 산림 0.05~0.2 > **물 0.05~0.1** |
| 분광반사율 순서 | **토양 > 식물 > 물** |
| red edge | 식생은 **적색광 흡수, 근적외 급상승**. 이 차이가 NDVI의 원리 |
| NDVI | **(NIR − Red)/(NIR + Red)**, 범위 −1~+1. 식생 활력 ↑일수록 +1에 근접 |
| GIS 정의 | 지리정보를 수치화·입력·저장·처리하고 분석·종합해 제공하는 시스템 |
| GIS 구성요소 | **하드웨어·소프트웨어·데이터(DB)·인력**. CPU는 HW 하위, 공간/속성정보는 DB 하위 → 동일 위계 나열 불가 |
| 공간정보 vs 속성정보 | 공간=**점·선·면**(위치·형태) / 속성=**정성·정량**(그것이 무엇인지). **벡터/래스터는 공간데이터의 구분** |
| 래스터 | Cell·Grid Matrix, **확대하면 깨짐**, .jpeg/.png/.gif, 용량 큼, 낮은 수준 분석 |
| 벡터 | 점·선·면, **확대해도 안 깨짐**, .pdf/.autocad/.svg, **용량 작음**, 고수준 분석. 단점은 복잡 형상 연산 부담 |
| GIS 처리순서 | **자료 획득 → 자료 전처리 → 자료 관리 → 조정과 분석 → 결과 출력** |
| GIS 장점 | 비용·시간 절약, 유지관리 용이, 수치기준 표준화, 의사결정 지원 |
| 좌표체계 | 우리나라 국가기본도 = **TM**(평면직각좌표계) |
| TM 원점 | **위도 38°N** 기준, 서부 125°E·중부 127°E·동부 129°E·동해 131°E **4개 혼용** |

| EPSG / WGS84 | EPSG는 **좌표계 식별코드**(5186 중부TM, 4326 WGS84) / WGS84는 **GPS 전지구 측지계** |
