# 블렌더 모형 · 도면 소개 영상

> CLAUDE.md 에서 옮겨 온 문서(2026-10).

## 블렌더로 도면을 세운다 — `make428.py` · `make401.py`

치수가 맞아야 하는 그림(입체 평면도·축측도)은 **이미지 모델로 만들지 않는다.** 화면에서
길이를 재지 못해 "주차 10대"·"연못 ⌀4m"를 몇 번 말해도 회차마다 달라진다(401 에서 22회차를
태우고 접었다). 블렌더 스크립트는 **숫자를 고치면 그 자리만 정확히 바뀐다.**

```bash
blender -b -P make428.py -- --out r01.png            # 축측도(45° 평행투영)
blender -b -P make428.py -- --out t01.png --top      # 평면 렌더 — 도면과 1:1 대조용
blender -b -P make428.py -- --out b01.png --bird     # 조감도(원근)
blender -b -P make428.py -- --out m.png --max --threads 14   # 5120px·1024샘플
```

- 파일 맨 위 **DIMS 한 곳만** 고친다. 좌표는 도면과 같은 단위(m)이고
  `bl(x, y)` 가 블렌더 좌표(Y 뒤집기)로 바꾼다
- **401 은 좌표를 다시 읽지 않았다** — `make_grid401_svg.py` 의 미터 좌표를 그대로 옮겼다.
  428 에서 가장 오래 걸린 일이 도면을 눈으로 읽는 것이었는데 그 일이 이미 끝나 있었다
- 401 은 **표고가 절대값**(71~72m대)이고 등고선에서 높이면을 만든다(IDW).
  계획고: 북동 진입광장 72.2 · 목재데크광장 72.0 · 남동 진입광장 71.6 · 마운딩 72.6.
  **수면은 도면에 없어 가정**했다(저수지 70.8 · 습지 71.0 · 실개천 70.9)
- 검증은 눈대중이 아니라 **겹쳐 보기** — 도면의 검은 선만 뽑아 1m 를 같은 화소로 맞춰
  평면 렌더 위에 빨갛게 얹고, 어긋난 곳의 숫자를 고쳐 다시 렌더한다

### 444 주차공원 — **CAD 도면의 좌표로** 세운다(`make444.py`, 2026-09)

사용자가 CAD 탭에 그린 시설배치도(서버 `CadDrawing` pk=3 '주차공원 444')의 **점 좌표(m)를 그대로** 옮겼다 —
401 이 모눈종이 SVG 좌표를 쓴 것과 같은 길이다. 부지 x -5~145 · y 0~107(블렌더 Y = 107 − y), 평탄. 401 의 부품
(`mat`·`brick_mat`·`tree`·`bed_shape`·`scatter_species`·`bench`·`render`)을 그대로 가져오고 주차칸 선·장애인 칸·
차량(칸의 46%)·모임지붕(`hip_roof` — 원뿔을 늘리면 지붕이 비틀려 마름모가 됐다)·주변(주거지 · 상업지 · 광로 ·
지하철 출입구)을 더했다. 식재는 성운 배식평면도 수목수량표 20종

```bash
blender -b -P make444.py -- --out t.png --top --samples 24     # 평면 — ov444(도면 선 겹치기)로 검증
blender -b -P make444.py -- --out a.png --hq --samples 256     # 축측도 3840×2560
blender -b -P make444.py -- --out b.png --bird --hq --samples 256
```

- **벽돌 무늬는 물체 좌표(m)로 깐다**(`brick_mat` 의 `TexCoord.Object`). 기본 생성 좌표는 판 크기에 비례해 늘어나,
  큰 보도 판에서 벽돌 한 장이 몇 m 가 됐다. 이제 `scale` 은 1m 당 개수라 소형고압블럭 2.5 · 판석 0.8
- **모형이 정확하면 GPT 실사는 한 번에 된다** — 조감도 · 입체평면도 · 평면도 모두 1~2회차. 도면만 주고 그리게 했을
  때는 7회차(조감도 탭의 옛 그림). 실사 평면도에 CAD 선을 얹으면 1:1 로 겹쳤다. 조감도는 1회차에 시점이 더 높고
  가까워졌고 길가에 가로수가 생겨, "카메라는 더 높지도 가깝지도 않다 · 첨부 그림에 없는 것은 더하지 말라"로 2회차에 잡았다
- `gen_note_image_gpt.py --ref` 는 **쉼표로 여러 장**을 받는다(첫 장이 고칠 그림)
- **CAD 도면(444)과 성운 답안 시설물배치도의 차이**(2026-09-28 대조 — 모형·실사에도 그대로 반영돼 있다):
  파고라 1개(성운 3 — 북서 휴게공간 왼쪽 위·왼쪽 아래 둘이 없다) · 조명등 15(성운 16 — 서측 보행로 맨 아래 하나) ·
  점표고 없음(성운 ⊕0.1 북측 보행로 · ⊕0.0 주차장 · ⊕0.0 서측 보행로) · 남동 '휴게공간' 글자 없음 ·
  주차대수 글자 '300대'(성운 '308대 (장애인 8 포함)') · 볼라드를 채운 점으로(성운 속 빈 원). CAD 도면을 채우면
  `make444.py` 의 상수(`PERGOLA`·`LAMPS` 등)를 고쳐 모형만 다시 돌리고, 실사는 그 렌더로 한두 회차면 된다

### 444 소개 영상용 — 모형이 솟아오르는 애니메이션(`anim444.py`, 2026-09)

`make444.py` 의 `build()` 를 그대로 불러 카메라를 평면(도면·실사 평면도와 같은 구도, ortho 190) → 45° 축측도(ortho 176)로 기울이고,
물체를 땅속에서 솟게 한다(화단·시설 → 건물 → 나무·가로등 → 자동차, 8초 192장). `blender -b -P anim444.py -- --out 폴더 [--only 0,60] [--samples 16] [--res 1920x1280]`

- **내리는 깊이는 물체 높이가 아니라 꼭대기 높이 + 0.6m** 다 — 나무 수관은 기준점이 수관 가운데라 높이만큼 내리면 땅 위 2~3m 에 떠 있었다(391개)
- 한 자리(1m 격자)의 부품(줄기+수관, 차체+유리+바퀴)은 **함께** 솟게 묶는다
- 블렌더 5 는 Action 이 층 구조라 `action.fcurves` 가 없다 — 보간은 기본값으로 둔다
- 1920×1280 · 16샘플 · 18스레드로 장당 약 30초(192장 1시간 30분)

### 도면은 **부지 좌표로** 읽는다 — `read_401_drawing.py`

사용자가 화면 조각을 붙여 주더라도 그것으로 읽지 말고 `_ls_drawing_refs/<번호>_성운/*.jpg`
원본(2400~2500px)을 연다. 붙여진 조각은 200px 남짓이라 인출선이 안 보이고, 그걸로 읽으려다
"2m 식재 띠가 있다" 같은 오독을 냈다.

```bash
python read_401_drawing.py planting 64 92 44 61 out.png   # 부지 x64~92 · y44~61 (m)
python read_401_drawing.py plan     -22 70 24 46 lead.png # 음수 x 로 라벨 블록까지
```

**축척은 눈대중으로 잡지 말고 경계선을 화소로 재서 잡는다.** 401 은 두 시트가 모두
**12.89 px/m** 였다(배식설계도 원점 538,279 · 기본설계도 400,468.5). 눈대중으로 잡았을 때는
y 가 7% 어긋나 남측 경계를 58m 로 읽었고, 그래서 "철쭉 띠가 57.6 에서 끝난다"고 본 것이
실제로는 경계선(60)까지 내려오는 띠였다.

- 경계선 찾기: 부지 범위 안에서 **60% 이상이 검은 가로·세로 줄**을 훑는다.
  도곽선이 함께 잡히므로 범위를 부지 안으로 좁힐 것
- **수량표는 마지막에 대조한다.** 수종을 자리로만 잡으면 수가 어긋난다 — 보행로 서쪽 열을
  느티나무로 넣어 두었더니 느티나무가 12주가 됐다. 남측 라벨 인출선을 따라가니 그 열은
  **메타세쿼이아 7주**였고, 바로잡으니 메타세쿼이아 5+7=12 · 느티나무 5+2=7 로 딱 맞았다.
  **수량이 맞아떨어지는 것이 자리를 제대로 잡았다는 신호다**
- 관목을 띠에 그냥 뿌리면 수량이 어긋난다(찔레 140 자리에 **854주**). 수량표 값에서 멈출 것
- 두 시트를 견줄 때는 **같은 축척·같은 창**으로 뽑아 나란히 붙인다. 401 의 기본설계도와
  배식설계도는 광장 왼쪽 변 82 · 동측 경계 90 · 보행로 서측 73 이 모두 일치했다

### 세 번 걸린 함정

- **`--bird` 가 `--max` 의 해상도를 되돌린다.** 인자 처리 차례 탓에 `--bird --max` 가 조용히
  1920×1280 을 뱉었다. 4분이면 끝나 버려 눈치채기도 어렵다(5120 이면 20분이 넘는다).
  지금은 `SAMPLES` 가 이미 잡혀 있으면 RES 를 건드리지 않는다
- **포장 판이 통째로 사라진다.** `slab(x0,x1,y0,y1,z,m,h)` 의 `z` 는 **윗면**이다.
  `z-h` 를 넘기면 포장이 h 만큼 잠겨, 지형(계획고−6cm)에 덮여 안 보인다
- **지형과 포장을 같은 높이에 두면 Cycles 에서 새까맣다**(EEVEE 는 덮어 가려 못 알아챈다).
  지형을 6cm 내리고 판마다 z 를 조금씩 어긋나게 둔다
- **띠(관찰로)를 바깥선+안선 한 ngon 으로 묶으면 안 된다.** 삼각분할이 even-odd 를 안 써서
  가운데까지 메워지고 법선이 뒤집혀 새까맣다. 두 선을 **길이 비례로 짝지어** 사각형을 잇는다
- **원통은 눕히는 회전을 빼먹기 쉽다.** 블렌더 원통은 Z 축이 기본이라 길이 40m 짜리가
  그대로 솟는데, **위에서 내려다보는 평면도·축측도에서는 점으로만 보여 안 보인다.**
  같은 까닭으로 428 동측 완충녹지가 경계에서 떨어져 있던 것도 조감도에서야 드러났다 —
  **모형을 고쳤으면 각도를 바꿔 한 번 더 본다**

## 도면 소개 영상 만들기 — 444 에서 정한 규칙 (2026-09)

**CAD 작도 재생 → 블렌더 모형 → 실사 → 드론 → 차 안 → 후진 주차** 흐름의 영상을 만들 때 지킬 것.
대표님이 하나하나 고쳐 준 기준이다 — 다른 도면(401 등)으로 만들 때도, 에이전트에게 맡길 때도 이대로 한다.
작업 폴더는 `Downloads\higgsfield_444`(영상·클립·시작 그림), 녹화·편집 스크립트는 세션 scratchpad 에 있었다.

### 흐름과 컷

| 차례 | 장면 | 만드는 법 |
|------|------|----------|
| 1 | CAD 작도 재생 | 로컬 개발 서버 `?tab=cad&play=<id>` 를 Playwright 로 녹화(1920×1280) |
| 2 | 완성 도면으로 확대 | 녹화 마지막 장면을 ffmpeg 로 확대(0.2초 멈춤 + 1.6초 확대) |
| 3 | 모형이 솟아오름 | 블렌더 `anim444.py`(8초) — 첫 장면이 확대 끝과 같은 구도 |
| 4 | 모형 → 실사 입체 | Kling 시작=블렌더 마지막 장면, 끝=실사 입체 |
| 5 | 실사 입체 → 조감 | Kling 시작=실사 입체, 끝=드론 컷 첫 장면 |
| 6 | 드론 비행 두 컷 | Kling, 앞 컷 마지막 장면에서 이어 만들기 |
| 7 | 드론이 도로의 흰 세단을 따라붙음 | Kling |
| 8 | **드론이 차를 빠르게 따라잡아 뒷유리로 들어가 운전석 시점이 됨** | Kling 시작=7 의 끝, 끝=운전석 그림 |
| 9 | 운전석: 진입로로 우회전 | Kling 시작=운전석 그림 |
| 10 | 운전석: 통로 한가운데 주행, 빈칸 옆에 섬 | Kling 시작=9 의 끝 |
| 11 | 높은 곳에서 본 후진 주차 | Kling 시작·끝 그림 둘 다 GPT 이미지로 |

**이어지는 컷은 앞 컷의 마지막 장면을 다음 컷의 시작 그림으로 쓴다**(ffmpeg `-sseof -0.05`). 이어 붙일 때 둘째 컷의
첫 프레임은 빼고(`-ss 0.042`) 이음 없이 붙인다. 시점이 바뀌는 곳(7→8 이전, 10→11)만 0.3초 녹아 넘어가게.

### 작도 녹화 설정 (대표님 기준)

- **제도판 전체가 보이게 고정한다** — 도구 줄·오른쪽 칸·상태줄을 CSS 로 감추고 '맞춤' 뒤 `svg.setAttribute('viewBox')`
  를 막아 화면을 잠근다(재생의 화면 따라가기가 영상에서는 흔들림으로 보인다)
- 녹화용 브라우저 설정(`localStorage.cadSet`): **굵은 샤프 0.3mm · 얇은 샤프 0.22mm · 보조선 빨강 `#e5534b` ·
  점 표시 끔(`pts:false`, `#cadShowPts` 도 끈다)** — 점과 번호는 영상에 없어야 한다
- 삼각자는 도면에 기록된 크기(`tri.pct`)로 나온다. 녹화 브라우저의 기본값(50%)을 따르면 선보다 짧아진다
- **처음 22초는 실제 재생 속도**(제대로 된 제도 장면), 그 뒤 빠르기를 올린다. 마지막 판(v9)은 타임랩스를 거의 실제
  속도(약 1.1배)로 두었다 — 대표님은 **천천히 그리는 쪽**을 원했다(20배 → 6.7배 → 2.2배 → 1.1배로 세 번 늦췄다)
- 작도가 끝나면 **보조선을 1.6초 동안 사라지게** 하고(CSS `opacity` 전이) 곧바로 넘어간다 — 끝에 멈춰 있는 시간이 길면
  안 된다(6초 → 2초로 줄였다)

### 차·주차장 장면 (대표님 기준)

- 차는 **테슬라 모델 3 같은 흰색 전기 세단, 로고·배지 없음.** 앞모양은 **그릴이 없는 매끈한 앞**이라고 꼭 적는다 —
  안 적으면 그릴 달린 일반 세단으로 바뀐다
- **주차된 차는 모두 같은 방향**이어야 한다. 흰 차가 후진 주차하면 주변 차도 모두 후진 주차(앞이 통로 쪽)로 그린다
- **진입은 연석이 끊긴 아스팔트 진입로로.** 운전석 그림에 진입로가 애매하면(붉은 보도 포장 등) 차가 보도 턱을 넘어
  들어간다 — 프롬프트로는 못 고치고 **시작 그림을 고쳐야** 한다(진입로·연석 끊김·우회전 화살표를 그려 넣었다)
- 통로에서는 **한가운데로** 달리게 하고 "화단·연석에 다가가지 않는다"를 적는다 — 안 적으면 화단 쪽으로 붙는다
- 드론 → 차 안은 **차보다 빨리 따라잡아 뒷유리로 파고드는** 흐름이 자연스럽다. "길에는 이 차 한 대뿐"을 적는다 —
  안 적으면 앞에 흰 차가 또 나타나 따라가던 차가 멀어진 것처럼 보인다
- 후진 주차는 AI 가 가장 어려워한다. **시작·끝 그림을 모두 주면**(주차 전·후) 차가 미끄러지지 않고 들어간다

### 힉스필드 CLI

- `npm i -g @higgsfield/cli` → `higgsfield auth login`(브라우저 승인. 밖에서는 휴대폰으로 승인한 뒤 뜨는
  `http://localhost:8765/callback?code=…` 주소를 받아 이 컴퓨터에서 `curl` 로 넘긴다) → `higgsfield workspace set <id>`
- 영상: `higgsfield generate create kling3_0 --mode pro --sound off --duration 5 --start-image A --end-image B --prompt … --wait`
  — **pro·소리 끔 8.75 크레딧**(4k 모드는 30). Kling 은 요청 비율과 상관없이 **입력 그림 비율(3:2)** 로 뽑는다
- 그림: `gpt_image_2_5 --variant sunburst --quality high --resolution 2k --image-references …` 2.75 크레딧. 마스크 옵션은 없다
- 비용은 먼저 `higgsfield generate cost …` 로 재고, 쓰기 전에 대표님께 여쭙는다
- 결과 주소 받기는 `curl` 이 "Connection was reset" 으로 자주 끊긴다 — `--retry 5 --retry-all-errors` 로 여러 번.
  업로드가 `HTTP 520` 으로 실패하면 그냥 다시 보낸다(크레딧은 안 나간다)

### Aside 브라우저 CLI · MCP (2026-09-29 설치)

- 설치: 공식 문서([docs.aside.com/help/developers](https://docs.aside.com/help/developers))의 Windows 절차 그대로 —
  `releases.aside.com/install.ps1` 을 받아 **서명이 `AT YOUR SIDE INC` 의 유효한 서명인지 확인한 뒤** 실행한다.
  서명 검사 없이 스크립트를 바로 돌리지 말 것
- 위치 `C:\Users\gocom\AppData\Local\Aside\CLI\current\aside.exe`(사용자 PATH 에 추가됨, 새 터미널부터 `aside`).
  설치한 판 1.26.916.1741, 갱신은 `aside --update`
- 로그인은 대표님 계정이라 대표님이 직접 한다: `aside login`
- MCP 는 **사용자 범위**로 등록했다(`~/.claude.json`, 모든 프로젝트에서 쓰인다):
  `claude mcp add --scope user aside -- "%LOCALAPPDATA%\Aside\CLI\current\aside.exe" mcp`.
  도구는 등록 뒤 **새 세션부터** 보인다. 되돌리기 `claude mcp remove --scope user aside`

### 편집·검사

- 장면 검사는 **ffmpeg 로 차례대로** 뽑아(`select='not(mod(n\,12))'` + `tile`) 눈으로 본다. OpenCV 의 `set(CAP_PROP_POS_FRAMES)` 는
  이 파일들에서 틀린 장면을 준다(한 번 "영상이 안 바뀐다"고 오판했다)
- 이음매는 앞 장면 끝과 뒤 장면 첫 장면을 반씩 겹쳐 확인한다
- Playwright 녹화 파일은 `context.close()` 뒤에야 다 쓰인다 — 바로 복사하면 파일이 없다고 나온다. 몇 초 뒤 복사
- 휴대폰으로 보낼 판은 **30MB 이하**(보내기 한도). 7분짜리는 1152×768 · crf 32 로 20MB 안팎
