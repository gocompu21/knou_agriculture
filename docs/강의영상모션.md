## 그래픽

- 화면에 빈자리가 없으면 확대 창(PIP) 대신 **화면 전체를 줌**한다(최대 1.85배)
- **줌은 대표님이 걸어 나가기 전에 끝낸다.** 1차에서 얼굴이 창 밖으로 나가 두 번 고쳤다
- 판에 붙는 표시는 같은 슬라이드 프레임들의 **중앙값으로 '사람 없는 빈 판'**을 만들어 몸 자리를 오려 내 사람 뒤로 숨긴다
- 시험 포인트는 **자막 띠 도장**으로 두면 아무것도 가리지 않는다. 실제 강조 말씀("시험 나와요·중요·외워야·헷갈려")에만
- 판서 자동 탐지는 얼굴·팔·붉은 사진을 잉크로 잘못 잡는다(65후보 중 18개만 썼다). **반드시 프레임을 보고 고른다**
- 자막 글꼴: 나눔 손글씨 펜 46px + 반투명 띠. 손글씨 펜은 V·S 대문자가 소문자처럼 보여 **학명만 세리프 이탤릭**
- 용어 카드는 병마다 처음 말씀하실 때 왼쪽 위

## 합성

- 8조각 동시, 우선순위 보통 이하, 조각당 메모리 감시(실제 0.5GB)
- 이음매는 PSNR 로 확인(35~39dB)
- 소리는 원본 음량 그대로(−17.4 LUFS, 차이 0.0 LU), 효과음은 목소리보다 25~38dB 작게
- 휴대폰판은 29.97fps, 영상 1.1Mbps + AAC 64k 2패스(50분에 약 440MB)

## 함정

- **ctypes `SetPriorityClass` 는 argtypes 를 정하지 않으면 64비트에서 조용히 실패**해 '보통' 우선순위로 돈다
- **돌고 있는 bash 스크립트를 고쳐 쓰면 깨진다**(이어 붙이기 단계가 깨졌다 — 이후 사본으로 돌림).
  파이썬으로 고쳐 쓰면 줄 끝이 CRLF 로 바뀐다
- 서브에이전트(대리)는 `REPORT_*.md` 같은 보고서 파일을 쓸 수 없다(하네스가 막음) → 보고는 글로 하고, 안부장이 파일로 저장한다
- 못 한 확인: 귀로 듣기, 실제 휴대폰 화면 — 대표님께 부탁드린다
- **Playwright 캡처는 PNG 한 장 0.64초, JPEG 품질 100 은 0.08~0.13초**다(PNG 대비 PSNR 44~45dB).
  x264 가 어차피 4:2:0 으로 줄이므로 JPEG 으로 받는다
- **ffmpeg 8 은 `-color_primaries` 를 줘도 unknown 으로 나온다** → 필터 끝에
  `setparams=color_primaries=bt709:color_trc=bt709:colorspace=bt709:range=tv` 를 붙인다
- 구글 폰트 펜 글꼴은 글자 조각을 나눠 받는다 → 그림 함수 안의 문자열까지 미리 불러와야
  첫 장면이 대체 글꼴로 찍히지 않는다
- 두 렌더가 같은 임시 파일 이름을 쓰면 섞인다 → 임시 이름에 pid 를 넣는다
- 모 대리 둘이 동시에 렌더하면 빈 메모리가 1GB 아래로 내려간다 → 렌더는 하나씩 차례로 한다
- 손글씨 펜의 '1' 은 막대 하나라 숫자로 안 읽힌다 → 숫자는 원 안에 넣는다
- Bash heredoc 은 `\\` 를 `\` 로 줄인다 → 역슬래시가 든 파이썬·JS 수정은 Edit 도구로 한다
