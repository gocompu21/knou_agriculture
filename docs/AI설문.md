# AI 모임 사전 설문 (/poll/)

대표님이 새로 여는 **AI 교육 모임**(수강생 8명 안팎, 한울회와 별개)의 사전 설문.
수강생은 강의실 스크린의 QR 을 휴대폰으로 찍어 답한다. 2026-10-24 정 대리가 만들었다.

## 주소

| 주소 | 화면 | 접근 |
|------|------|------|
| `/poll/` | 프로젝터용 QR(큰 QR·`hanulstudy.kr/poll/s` 글자·응답 수 5초마다 갱신) | 누구나 |
| `/poll/s/` | 설문(휴대폰 우선, 한 장 스크롤). QR 이 가리키는 곳 | 누구나(로그인 없음) |
| `/poll/thanks/` | 감사합니다 | 누구나 |
| `/poll/qr/` | `/poll/` 로 넘김(예전 주소) | |
| `/poll/count/` | 응답 수 JSON(QR 화면이 씀) | 누구나 |
| `/poll/stats/` | 통계 | 스태프(아니면 로그인 화면 → next 로 복귀) |
| `/poll/stats/csv/` | CSV(이름별 마지막 응답, `?all=1` 이면 모든 제출). UTF-8 BOM 이라 엑셀에서 바로 열림 | 스태프 |

화면 위 작은 링크: 설문 오른쪽 위 '관리자'(옅은 글씨), QR·통계 화면은 설문·QR·통계 서로 오가기.
세 화면 모두 `base.html` 을 상속하지 않는 독립 페이지다 — **한울회 이름·로고·메뉴를 넣지 않는다.**

## 구조

- 앱 `poll/` — 모델 `PollResponse`(이름·답 JSON·제출 시각). **이름 외 개인정보는 받지 않고 IP 도 저장하지 않는다**
- 문항은 `poll/questions.py` 한 곳(대표님 승인본 문구 그대로). 화면·검증·통계·CSV 가 모두 이 표를 쓴다
  - 답 키: `q2`, `q3_other`(기타 글), `q5`(목록), `q9_1`~`q9_4`, `q10_1`~`q10_4`
  - 8번은 '유료를 쓰고 있다'를 고르면 '어떤 것' 칸(`q8_other`)이 열린다
- 필수: 1·2·4·6·11·14·15. 빠뜨리면 그 문항 상자가 빨개지고 그 자리로 스크롤(JS), 서버도 같은 검사를 한다
- 11번은 3개를 고르면 나머지 보기가 잠긴다(서버도 3개 초과를 막는다)
- 같은 이름으로 다시 내면 새 응답으로 저장, 통계는 **이름별 마지막 응답만**(공백·대소문자 무시)
- QR 은 서버에서 `segno`(순수 파이썬, 의존성 없음)로 SVG 를 만들어 페이지에 넣는다 — 정적 파일 없음
  - 운영 주소면 `https://hanulstudy.kr/poll/s/` 로 고정(nginx 뒤라 http 로 보일 수 있어서)

## 도배 방지 — 교실 와이파이 함정

수강생이 교실 와이파이로 들어오면 **모두 같은 공인 IP** 다. 그래서 IP 한도는 1분 20회로 넉넉히 두고,
실제 막는 것은 **브라우저 쿠키(서명) 기준 30초에 한 번**이다. 처음에 'IP 당 1분 몇 회'로만 막으면
교실에서 서너 명이 동시에 내다가 막힌다. 캐시는 기본 LocMem(gunicorn 워커마다 따로)이라 IP 한도는 대략적이다.

## 통계 기준

- **수준 분류**(4번 컴퓨터 숙련 × 6번 AI 빈도), 판정 순서대로:
  1. 활용 중 — 6번이 '일주일에 몇 번' 이상 **그리고** 4번이 '문서 작성도 한다' 이상
  2. 입문 — 6번이 '써 본 적 없다'·'몇 번 해 봤다' **또는** 4번이 '전화·카톡 정도만'
  3. 써 봄 — 그 밖
- 9번 정답: 9-1·9-2·9-4 '맞다', 9-3 '아니다'(대화 기억은 서비스·설정에 따라 다름 — 화면에 주석). '모르겠다'는 틀림과 따로 센다
- 10번: 용어별 '처음 들음 / 들어 봄 / 설명할 수 있음' 비율
- 11번·13번 순위, 14번 기기, 문항별 분포(막대, CSS 만), 주관식(12·16) 모아 보기, 사람별 전체 표
