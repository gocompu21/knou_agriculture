### 계산 문항의 답 — 자연생태복원 실기와 같은 꼴

계산·표그림 33건의 답을 `answer_items` 두 항목으로 나눴다(`ls_calc_to_items.py`).
자연생태복원 실기 39건 중 37건이 이미 이 꼴이라 맞춘 것이다.

```
항목 1   계산)
         <풀이 방향 한두 줄>
         [eq]<식> = <대입> = **<결과>**[/eq]
항목 2   답) <최종 답만 짧게>
```

- 식은 **`[eq]` 안에 두어야** `qtext` 가 `a / b` 를 세로 분수로 쌓는다(`wrap_ls_eq.py`).
  분자가 `·` 로 이어진 공식은 괄호로 묶어야 통째로 분수가 된다 — `Q = 60·q·f·E / Cm`
  는 `E/Cm` 만 분수가 됐다
- **'답)' 문구는 손으로 정한다.** 마지막 식의 값을 기계로 뽑으면 중간값이 답으로
  올라간다 — 2023-1 7번은 ①삽날 용량 2.56m³ 를 거쳐 계산하지만 묻는 것은
  ②사이클시간과 ③시간당 작업량이다. `FINAL` 표에 문항마다 적어 두었다
- **표가 곧 답인 문항**(2025-1 2번 야장 채우기)은 표를 '답)' 항목으로 옮기고 볼드를
  넣지 않는다. 풀이 쪽에 표를 남기면 답 항목이 '10.0 / 9.9 / …' 숫자 나열이 된다
- 자연생태복원 쪽에도 `[eq]` 없이 남아 있던 계산 2건을 같은 꼴로 맞췄다
  (`fix_eco_calc_items.py`)
- **한글 비율 35% 규칙에서 빠진 2건은 손으로 넣었다**(`fix_ls_frac_rest.py`).
  `일 최대이용객 = 연간이용자수 × 최대일률 = 54,000 × 1/60` 은 라벨이 한글이라
  설명 문장으로 걸러졌다. 조경산업기사 2023-4 3번은 묻는 것이 둘이라 항목도 둘로 갈랐다
- **항이 한글인 분수는 `a / b` 규칙이 세우지 않는다.** `[frac]분자|분모[/frac]` 로
  적어야 한다 — 농약 희석량 공식의 `농약주성분농도(%) / 추천농도(%)` 가 그랬다

### answer_text 만 있던 5건도 항목으로 (`fix_ls_answer_items.py`)

`build_rubric` 은 `answer_items` 가 비면 **답 전체를 채점 포인트 하나**로 만든다.
뿌리분 3형태(조경산업기사 2023-2 2번, 5.5점)는 셋을 묻는데 한 덩어리라 부분점수가
없었다 — 항목 3개로 갈라 1.83점씩 나눴다. 나머지 4건은 서술 2·순서 나열 2라
항목 하나가 맞다(순서는 통째로 맞아야 맞는 답이라 쪼갤 수 없다).

- **채점에 안 쓰는 곁가지는 「해설」(`reference`)로 옮긴다.** 개화 시기 월,
  "세 형태 모두 분의 너비는 A" 같은 공통 조건을 채점 포인트 안에 두면 순서만
  바르게 쓴 답안이 "월을 안 적었다"로 깎인다
- 이로써 조경 실기에 `answer_text` 만 남은 문항은 0건이다

### 그림 검수는 두 단계다 — 원도 대조를 빠뜨리면 소용없다

화면으로 보는 것(①)과 **원도와 대조하는 것**(②)은 다른 일이다. ②를 건너뛰어
**뿌리분 3형태(산기 2023-2 2번)를 통째로 잘못 그렸다.**

| | 무엇을 보나 | 걸리는 오류 |
|---|---|---|
| ① 브라우저 | 숫자·치수·라벨 잘림, 겹침, 넘침 | 보기 흉한 것 |
| ② 원도 대조 | 곡선/직선, 변의 수, 치수선 자리 | **틀린 것** |

답 항목에 적어 둔 '조개모양'·'접시모양'이라는 **이름에 이끌려** 곡선으로 그렸는데,
교재 원도는 곡선이 하나도 없었다 — 셋 모두 너비 A 의 직사각형에서 아래를 각진
V자로 좁혀 내리고(일반 A/4, 심근성 A/2), 천근성만 V 없이 납작한 직사각형이다.
화면에는 멀쩡히 나오므로 ①로는 절대 걸리지 않는다. **원도를 못 구하면 그리지 말고
자리표시로 남겨 둔다.**

### 그림이 곧 답인 문항은 `answer_text` 에 넣는다

"형태를 그리고 크기의 비율도 기입하시오"(산기 2023-2 2번)처럼 **그리는 것 자체가
답**인 문항은 그림을 문제문에 두면 답을 미리 보여 주는 꼴이다. 표·계산식과 같은
자리인 `answer_text` 에 둔다 — 학습·목록 화면 모두 `answer_text` 를 qtext 로 렌더한다.
문제문의 그림은 **제시 자료일 때만** 둔다(수준측량도·시비법 그림 등 8건이 그렇다).

### 그림을 고쳤을 때 (`add_ls_figures.py --refresh`)

`[svg]키[/svg]` 자리표시는 한 번 넣으면 사라져, 그림을 고쳐도 넣기 경로로는 다시
들어가지 않는다. **키에 `ls-연도-회차-자격증-번호` 가 들어 있어** 어느 문항인지

(한 문항에 그림이 둘이면 가릴 수 없어 건너뛴다). 뿌리분 그림의 `보통수종` 을
문제문·답과 같은 `일반수종` 으로 고칠 때 썼다 — 나머지 8건은 바이트가 같아 그대로 넘어갔다
- 두 스크립트 모두 멱등이다 — `answer_items` 가 이미 있으면 건너뛴다. 배포는
  서버에서 그대로 한 번 돌리면 된다

### 적산 공식 정리 (`load_ls_note.py`)

교재 PART 6 조경적산의 **이론 20쪽**(교재 276~283, 293~304)을 읽고 공식과 수치만
추려 `GisaEssayNote`(slug `calc`)에 넣었다. 8,200자, 8개 절 — 토량의 세 상태 /
토공량 산정 / 인력운반 / 기계화 시공 / 재료량 / 수목식재 품 / 공사비 체계와
원가계산 / 계산과 맺음 규칙. 각 절은 **공식 → 기출 → 함정** 순서다.

- **이론을 그대로 옮기지 않았다.** 적산의 알맹이는 표준품셈 수치와 원가계산
  체계라 사실이고, 보호되는 것은 표현과 구성이므로 서술과 표를 새로 썼다
- **두 자격증에 같은 내용을 넣는다** — 필답 범위가 거의 같고 적산은 완전히 겹친다
- 계산형 33문항과 연결해 두어(「기출」줄) 공식에서 문항으로 건너갈 수 있다
- 넣은 표: 체적환산계수 3×3, 경사지 운반 환산계수, 군식 식재밀도, 벽돌쌓기
  기준량, 요율을 곱하는 밑변, 간접노무비율, 금액의 단위 표준

#### 노트 화면이 조경 형식도 받도록 넓혔다

`parse_note_items` 가 `## N회 · 분류 · 주제`(자연생태복원 꼴)만 항목으로 갈랐다.
조경 정리는 빈도·분류가 없으므로 그 꼴로 안 갈리면 **평범한 `## 제목`으로 다시**
가르고 freq 0·group '' 으로 채운다. 화면은 freq 가 0이면 회차·분류 배지와
걸러 보기 단추를 감춘다(`has_freq`).

라벨 상자(공식·함정 등)는 **한 줄만** 잡던 것을 다음 라벨·구분선·표까지로 넓히고
`nl2br` 을 켰다 — 조경 쪽은 공식이 여러 줄이라 첫 줄만 상자가 되고 나머지가 본문으로
흘렀으며, 마크다운이 단일 개행을 무시해 식이 한 줄로 붙어 보였다.

**학습전략 화면은 `freq58` 노트가 있을 때만 연다.** 본문에 58주제·공식 18·예상문제
36건 같은 자연생태복원 수치가 문장에 박혀 있어, 조경에 노트가 생겼다고 열리면 안 된다.

### 실기 쪽집게 노트 — 주제를 손으로 배정한다 (2026-09)

식물보호는 발문 유사도로 군집을 만들고(`tag_essay_frequency`) 분류만 사람이 붙였다.
조경은 **주제까지 사람이 배정한다.** 한 문항에 사실 하나를 묻는 꼴이 많고, 같은
기준표(도시공원 규모·식재 토심·원가 요율)의 **다른 칸**이 회차마다 나오는데 글자
유사도로는 그 칸들이 한 주제로 묶이지 않는다.

- 주제표 `_ls_topics.json` — 9분류·97주제. 기사 132 + 산업기사 40 + 학원예상 24,
  196문항 전부가 정확히 한 주제에 들어간다. 분류표는 `essay_topics.TOPIC_GROUPS['조경']`
- `load_ls_topics.py --apply` 가 `topic_key`·`topic_group`·`freq_rounds`·`written_freq` 를
  적고 제목을 `essay_topic_titles.json` 에 `key:<주제키>` 로 쓴다.
  **새 문항을 넣은 뒤 이것을 돌리면 배정되지 않은 문항 목록이 나온다** — 거기 맞춰 주제표에
  추가한다
- **주제키는 주제 id 의 md5 앞 16자**라 제목·배정을 고쳐도 바뀌지 않는다. 해시 군집
  키로 덮어쓰지 않도록 `tag_essay_frequency` 의 `LOCKED` 에 두 급수를 넣었다
- 빈도(`freq_rounds`)는 기사·산업기사 **기출 시험지 수**다(`SIBLING_GROUPS`). 모수 15장,
  최다가 원가 요율 5장이라 별 기준은 4/3/2(`STAR_CUTS`)
- **학원예상 문항도 같은 주제키를 받는다.** `build_textbook` 이 주제 안에 함께 펼치되
  빈도·회차 배지에는 넣지 않고 머리에 "학원 N"만 적는다. 문항 목록(`essay_siblings`)은
  배지를 '학원'으로 달고 기출 뒤에 둔다. 학원 문항만 있는 주제는 정리글이 있을 때만 보인다
- 정리글은 `topics` 노트(조경기사에만 단다) — 주제마다 `### 핵심 정리 / 왜 그런가 /
  시험에서는`. 분류별 파일 `_ls_note/gN.md` 를 `load_ls_topics_note.py --apply` 가 이어 붙이며
  머리글(회수·분류·제목·주제키)을 DB·주제표와 대조해 하나라도 어긋나면 넣지 않는다

#### 자료 수정은 화면에서 (WYSIWYG)

스태프는 '수정'을 눌러 **Toast UI Editor 3.2.2** 로 보이는 대로 고친다(아래 Markdown 탭에서
원문도 본다). 저장은 `drawing_ref_update` 로 마크다운을 보내고, 고친 자리만 다시 그려 받는다.

- **WYSIWYG 은 raw SVG 를 지운다.** 편집기에 넣기 전에 SVG 를 `⟦그림 N⟧`·`⟦기호 N⟧` 표식으로
  바꿔 두었다가 저장할 때 그 자리에 도로 넣는다(`protect`·`restore`). 표식을 지우면 그림도 사라진다
- **Toast UI 는 `~` 처럼 파이썬 마크다운이 모르는 글자 앞에도 역슬래시를 붙인다.** 그대로 두면
  화면에 `444\~446쪽` 으로 보이므로, 아는 이스케이프(`!#()*+-.>[]_` 백틱 `{}|` 역슬래시)만 남기고 뗀다
- 불렛 `-` 를 `*` 로, 이어지는 줄 들여쓰기를 2칸에서 4칸으로 바꿔 내놓지만 렌더 결과는 같다
  (13,524자 자료로 왕복 시험: SVG 7개·표 2개·제목·목록 모두 그대로)
- 그림 올리는 단추는 뺐다 — 올릴 곳이 없어 data URI 로 들어가면 본문 4만 자 제한에 걸린다
