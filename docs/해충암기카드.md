## 모델·API

`PestCard`(no·slide·name·group·image·desc·note) / `PestQuizAttempt`(user·card·selected·
is_correct·created_at). 마이그레이션 `0029_pestcard_pestquizattempt`.

| URL | 뷰 | 설명 |
|-----|-----|------|
| `/gisa/pest/next/` | `api_next` | `?mode=all\|crop\|tree\|wrong&seen=` |
| `/gisa/pest/answer/` | `api_answer` | POST `card`·`selected` → 정답·구분·설명 |
| `/gisa/pest/reset/` | `api_reset` | 내 기록 삭제 |
| `/gisa/pest/list/` | `api_list` | 152종 목록 |

- **보기 넷은 서버가 뽑는다.** 농약 DVD 는 묻는 것이 늘 셋(살충·살균·제초)뿐이라
  화면에 박아 두면 되지만, 해충은 152종 가운데 하나라 그때그때 만들어야 한다
- **오답 보기는 같은 구분(농작물·수목)에서 먼저 고른다.** 농작물 해충 사진에
  수목 해충만 섞어 놓으면 사진을 보지 않고도 답이 갈린다
- 오답 판정은 카드별 **가장 최근** 풀이 기준(`_latest_wrong_ids`) — 잡초·농약과 같다

## 사진 잘라내기 — 색이 **이어지는 길이**로 가른다

슬라이드는 어느 장이나 같은 짜임이다: **좌상단 해충명 · 우상단 설명 · 그 아래 사진 여러 장.**
사진은 **낱장으로 가르지 않고 통째로** 쓴다(사용자 지시) — 사진 안의 캡션도 함께 둔다.
실물 슬라이드를 보는 감각이 살고, 낱장으로 가르면 크기가 제각각이라 오히려 어수선하다.

경계 찾기에 **두 번 헛짚었다.**

1. 행마다 **흰 배경 비율**을 재어 가르려 했더니 **해충명 글자에 걸렸다** —
   큰 글씨라 행 비율이 사진만큼 높다(153번은 11행에서 멎었다)
2. **유채색 비율**로 바꿨더니 **이름이 빨간 글씨인 장**에서 또 걸렸다
   (153번 큰이십팔점박이무당벌레 — 답이 통째로 문제 사진에 찍혔다)

글자는 획이 굵어도 **글자 사이가 끊겨 한 행에서 40px 넘게 이어지지 않는다**(실측 33~39px).
사진은 수백 px 이어진다. 그래서 **흰 배경이 아닌 화소가 가로로 150px 이상 이어지는 행**을
사진으로 본다.

거기에 **세로 조건**을 더한다 — 그런 행이 **25행 이상 이어져야** 사진이다.
슬라이드 맨 위에 한 줄짜리 장식 선이 그어진 장이 있어(14·17·25번, `y=5` 에 x130~1072)
행 하나만 보면 거기서부터 잘려 이름과 설명이 통째로 문제에 들어갔다.

> **사진에 답이 적힌 장이 있다.** 캡션에 해충명이 박혀 있거나(153번) 사진 속 글자가
> 답을 흘린다. 사용자 지시로 **가리지 않고 그냥 두었다** — 가리려면 사진을 덧칠해야
> 하는데 그러면 사진이 상한다.

## 만드는 절차

작업 파일은 `C:\Users\gocom\AppData\Local\Temp\hc` 에 있다.
**Windows MAX_PATH 260** 때문에 워크트리 안의 스크래치패드를 쓰면
`os.path.exists` 가 거짓을 돌려준다(`ls` 로는 보인다) — 짧은 경로를 쓴다.

```
cut.py                  슬라이드 → out/q###.jpg(문제 사진) + out/h###.png(상단 글)
pests_01.py … _09.py    판독 결과 (슬라이드번호, 해충명, 구분, 설명)
build.py                위 아홉을 모아 _pest_cards.json + media/pests/ 로 옮김
load_pest_cards.py      검증 → --apply 로 DB 반영
```

- 상단 글 152장은 38장씩 이어 붙여(`bat/b01.png`…`b38.png`) **Claude 가 직접 읽었다**
  — 외부 API 를 쓰지 않는다
- `load_pest_cards.py` 는 **해충명 중복**과 **사진 파일 없음**을 먼저 본다.
  사진이 없으면 화면에 깨진 그림이 뜬다
- 슬라이드 **116번 솔잎혹파리의 설명이 솔수염하늘소의 것**으로 보인다.
  원본이 그렇게 되어 있어 고치지 않고 `pests_07.py` 의 `SUSPECT` 에 적어 두었다

## 배포 — 사진은 git 밖이라 따로 올린다

```bash
git push origin HEAD:main
ssh -i "C:\AWS\knou_key2.pem" ubuntu@hanulstudy.kr
cd ~/knou_agriculture && git pull && python manage.py migrate
python load_pest_cards.py --apply
sudo systemctl restart gunicorn
```

`media/` 는 `.gitignore` 에 있으므로 사진 152장은 **tar 로 올린다**(잡초 카드와 같다).

```bash
tar -czf pests.tgz -C media pests
scp -i "C:\AWS\knou_key2.pem" pests.tgz ubuntu@hanulstudy.kr:~/
ssh ... 'cd ~/knou_agriculture && tar -xzf ~/pests.tgz -C media && rm ~/pests.tgz'
```

사진을 먼저 올려야 `load_pest_cards.py` 의 파일 검사를 통과한다.
