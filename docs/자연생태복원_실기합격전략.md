# 자연생태복원기사 실기 필답 — 데이터로 확인한 합격 전략

> 회원 공지용으로 쓴 글이다. `essay_pass` 뷰가 **첫 `---` 뒤**를 읽어 화면에 보여 준다.
>
> **수치의 출처는 우리 DB 다** — 자연생태복원기사 실기 필답 기출 **51개 회차
> 736문항**(2005-1 ~ 2026-2). 회차를 더 넣으면 아래 숫자가 모두 달라지므로,
> 갱신할 때는 `topic_key` 기준으로 다시 세어 고칠 것. 세는 방법은 이렇다 —
> 회차마다 "그 문항의 `topic_key` 가 **앞선 회차에** 나온 적이 있나"를 보고,
> 배점(`points`)으로 가중해 45점 만점으로 환산한다.
>
> **식물보호 글(`실기합격전략.md`)의 수치를 옮겨 쓰지 말 것.** 두 종목은 성격이
> 다르다 — 식물보호는 기출이 18장뿐이라 재출제율이 높고 좁게 파는 것이 먹히지만,
> 이쪽은 51회차에 서로 다른 주제가 469개라 **좁히면 오히려 점수가 무너진다**.
> 그 차이가 이 글의 핵심이다.

---

자연생태복원기사 실기(필답형)를 준비하는 회원들께 드리는 글입니다.
감이나 경험담이 아니라, 우리 사이트에 쌓인 **실기 필답 기출 51개 회차 736문항**
(2005년 ~ 2026년)을 직접 세어 얻은 결과입니다.

## 한 줄로 말하면

**기출 주제를 빠짐없이 훑으면 합격선에 닿습니다. 다만 빈출만 골라 보면 떨어집니다.**

## 1. 목표는 만점이 아니라 30점입니다

먼저 이 시험의 셈법을 정확히 아셔야 합니다.

| 항목 | 내용 |
|------|------|
| 필답형 | **45점** · 1시간 30분 · 15문항 안팎 |
| 작업형 | **55점** · 3시간 |
| 합격 | 둘을 더해 **60점 이상** |
| 과락 | **없습니다** (개별 과목 과락 조항이 없습니다) |

과락이 없다는 것이 전략의 출발점입니다. **필답에서 30점을 확보하면 작업형은
55점 중 30점만 받아도 합격**입니다. 반대로 필답을 20점에 두면 작업형에서 40점,
즉 73%를 받아야 합니다. 도면 작업에서 73%는 훨씬 어렵습니다.

그러니 필답의 목표는 **45점 중 30점(67%)** 입니다. 만점을 노리실 필요가 없습니다.

## 2. 기출 주제를 다 보면 평균 29.3점입니다

"그 회차 이전까지 한 번이라도 나왔던 주제"만 풀 수 있다고 가정하고, 최근 8개
회차를 실제로 채점해 봤습니다.

| 회차 | 기출에 있던 주제로 얻는 점수 |
|------|------|
| 2023-3회 | 31.0 / 45점 (68.9%) |
| 2024-1회 | 26.5 / 45점 (58.9%) |
| 2024-2회 | 31.0 / 45점 (68.9%) |
| 2025-1회 | 25.0 / 45점 (55.6%) |
| 2025-2회 | 29.5 / 45점 (65.6%) |
| 2025-3회 | 28.5 / 45점 (63.3%) |
| 2026-1회 | 29.0 / 45점 (64.4%) |
| 2026-2회 | 34.0 / 45점 (75.6%) |
| **평균** | **29.3 / 45점 (65.1%)** |

목표선이 30점이었습니다. **기출만 제대로 보면 딱 그 언저리에 닿습니다.**
바꿔 말하면, 기출을 대충 보면 합격선에 못 미칩니다. 여유가 없습니다.

## 3. 빈출만 골라 보면 안 됩니다 — 이 종목의 함정

여기가 다른 종목과 가장 다른 점입니다. 같은 방식으로, **이전에 두 번 이상**
나온 주제만 공부했다고 가정하면 이렇게 됩니다.

| 공부 범위 | 최근 8회차 평균 득점 |
|-----------|------|
| 한 번이라도 나온 주제 **전부** | **29.3점** |
| 두 번 이상 나온 주제만 | 14.4점 |
| 세 번 이상 나온 주제만 | 6.6점 |

절반 밑으로 무너집니다. 까닭은 숫자에 있습니다 — 51개 회차에 **서로 다른 주제가
469개**이고, 그중 두 번 이상 나온 것은 160개, 세 번 이상은 59개뿐입니다.
**대부분의 주제는 한 번씩만 나오고, 시험지의 절반은 그 한 번짜리들로 채워집니다.**

> 다른 종목 후기에서 "빈출 50개만 외우면 된다"는 말을 보셨다면, 그건 기출이
> 스무 장 남짓인 종목 이야기입니다. 이 시험에는 그대로 적용되지 않습니다.

그러니 **넓게, 대신 얕게** 가십시오. 한 주제에 30분을 쓰는 것보다 열 주제를
5분씩 훑는 편이 이 시험에서는 점수가 높습니다.

## 4. 어디에 시간을 나눌 것인가

최근 10개 회차의 **배점 기준** 비중입니다. 문항 수가 아니라 점수 몫입니다.

| 분야 | 배점 몫 |
|------|--------|
| 생태학 기초 | 21.4% |
| 법규·제도 | 17.9% |
| 경관생태 | 15.6% |
| 생태조사·분석 | 15.0% |
| 기반환경 복원 | 11.7% |
| 복원 계획·설계 | 11.4% |
| 생태시설물·현장관리 | 4.3% |
| 환경영향평가 | 2.7% |

앞의 네 분야가 **70%** 입니다. 시간이 모자라면 뒤의 둘(생태시설물, 환경영향평가)은
뒤로 미루셔도 손해가 7% 남짓입니다.

**법규·제도가 2위(17.9%)라는 점을 놓치지 마십시오.** 생태자연도 등급, 생물권보전지역
공간구획, 보호지역 유형처럼 **외우면 그대로 점수가 되는** 자리입니다. 이해가 필요한
생태학보다 시간 대비 효율이 좋습니다.

## 5. 유형별로 답 쓰는 법이 다릅니다

| 유형 | 배점 몫 | 요령 |
|------|--------|------|
| 열거 | 34.8% | **묻는 개수만 쓰십시오.** 3가지를 물으면 3개만 |
| 서술 | 33.3% | 정의 한 줄로 끝내지 마십시오 (아래 7번) |
| 계산 | 10.3% | 단위까지 쓰십시오 (아래 6번) |
| 단답 | 9.7% | 맞거나 틀리거나입니다. 괄호 부연은 선택 |
| 빈칸 | 7.6% | 번호기호는 신경 쓰지 않아도 됩니다 |
| 표·그림 | 4.3% | 축과 이름표를 반드시 답니다 |

**열거형에서 개수를 지키는 것이 생각보다 중요합니다.** 3가지를 물었는데 5개를
적으면, 실제 채점에서는 **먼저 쓴 3개만** 봅니다. 확실한 것을 앞에 쓰십시오.

## 6. 계산은 공식 18개가 전부입니다

계산 문제는 최근 10개 회차에서 **회차당 1.2문항, 배점의 10.3%** 입니다.
그런데 쓰이는 공식은 열여덟 개뿐이고, **수치까지 똑같은 문제가 되풀이**됩니다.

> 예: 인구증가율 문제는 2005-3 · 2015-1 · 2018-2 · 2020-3 · 2024-2 로 다섯 번,
> Shannon-Wiener 종다양성지수는 2011-2 · 2014-2 · 2017-3 · 2023-3 으로 네 번.

쪽집게 노트의 **「계산 공식 18」** 을 손으로 한 번씩 풀어 두십시오. 눈으로 읽으면
시험장에서 대입 순서가 헷갈립니다. 4.5점은 확보하고 들어가는 셈입니다.

**단위를 빠뜨리지 마십시오.** 문제가 단위를 지정했으면(`작업량(m³/hr)을 구하시오`)
숫자만 써도 정답이지만, 지정하지 않았으면 단위가 없는 답은 오답입니다. 단위가
틀리면(m² ↔ m³) 숫자가 맞아도 점수를 받지 못합니다.

## 7. 같은 주제라도 요구가 커집니다

기출을 다 봐도 29점에서 멈추는 까닭이 여기 있습니다. **같은 주제가 더 깊게**
나옵니다.

| 회차 | 물음 |
|------|------|
| 2022-3회 | 추이대란 무엇인지 그 **정의**를 쓰시오 |
| 2026-2회 | 추이대의 종다양성이 **높은 까닭**을 서술하시오 |

정의만 외운 분은 뒤쪽에서 절반을 잃습니다. 그래서 주제마다 **① 무엇인가 ② 왜
그런가 ③ 어디에 쓰는가** 세 층으로 정리해 두셔야 합니다. 쪽집게 노트의
**⚠️ 표시**가 붙은 주제가 실제로 요구가 커진 이력이 있는 자리입니다.
거기부터 보십시오.

## 9. 이렇게 하십시오 — 4주 계획

| 주 | 할 일 |
|----|------|
| 1주 | **기출고사로 최근 8회차를 풀어** 지금 몇 점인지 확인합니다. 채점은 AI가 합니다 |
| 2~3주 | **쪽집게 노트를 분야 순서대로 훑습니다.** 생태학 기초 → 법규·제도 → 경관생태 → 생태조사. 한 주제에 오래 머물지 마십시오 |
| 3주 | **계산 공식 18개**를 손으로 풀어 봅니다 |
| 4주 | **오답노트만** 다시 풀고, 남은 회차로 실전 연습을 합니다 |

풀이는 **시험지를 인쇄해 손으로 쓰는 쪽**을 권합니다. 실기는 실제로 손글씨이고,
사진을 올리면 판독해서 그대로 채점해 드립니다. 1시간 30분에 15문항이면 **문항당
6분**입니다. 이 속도는 화면 입력으로 연습하면 감이 잡히지 않습니다.

## 마지막으로

이 시험은 **아는 것을 넓게 펴 놓는 사람**이 붙습니다. 469개 주제 중 어느 것이
나올지는 아무도 모르지만, 기출에 한 번이라도 나온 주제를 다 훑으면 평균 29.3점,
거기에 계산 공식과 요구 확장 대비를 얹으면 35점 언저리입니다. 그러면 작업형에서
25점만 받아도 합격입니다.

기출부터 시작하십시오.
