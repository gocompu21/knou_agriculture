# 주제 분류 기준 (자연생태복원기사 실기 필답)

각 문항이 **실제로 무엇을 묻는지**로 나눈다. 출제기준 8항목(실무 수행 순서)이
아니라, 수험생이 공부할 때 묶어서 볼 단위다.

| 값 | 분류 | 무엇이 여기 오는가 |
|---|------|------------------|
| 1 | 생태학 기초 | 천이, 개체군·군집 생태, 먹이망·에너지 흐름, 물질순환(탄소·질소), 종다양성 개념, 종간 상호작용(경쟁·공생·기생), 내성범위·제한요인, 생물군계·기후대, 생태계 구조와 기능, 유효개체군·유전다양성, 외래종·교란종의 생태적 원리 |
| 2 | 경관생태 | 패치(조각)·코리더(통로)·매트릭스(바탕), 파편화·단편화, 가장자리 효과, SLOSS, 도서생물지리설, 메타개체군, 생태축·생태네트워크, 연결성, 경관지수, 비오톱 개념과 지도화 |
| 3 | 생태조사·분석 | 조사 방법(방형구·belt transect·라인·포획·표지재포획·무선추적·트랩), 식생조사, 개체수·피도·빈도·우점도·중요도 산출, 다양도·유사도 지수 계산(Shannon·Simpson·Jaccard), 원격탐사·GIS, 모니터링 방법과 주기, 자연환경조사 체계 |
| 4 | 복원 계획·설계 | 복원·복구·대체 개념, 복원 목표종 선정, 서식지 유형별 복원(숲·초지·습지·하천), 생태통로, 대체습지, 식재·파종·이식 계획, 수생식물 배치, 참조생태계, 복원 절차와 구상, 미티게이션 |

| 6 | 생태시설물·현장관리 | 관찰·체험·편의·관리 시설(탐조대·데크·안내판·유도울타리), 공정·예산·품질·안전 관리, 시공법, 품셈·내역·원가, 유지관리(전정·시비·멀칭) |
| 7 | 환경영향평가 | 환경영향평가·전략환경영향평가·소규모 환경영향평가, 스코핑, 협의 절차, 저감방안, 사후환경영향조사, 평가 대상사업 |

## 판정이 애매할 때

**"무엇을 알아야 답할 수 있는가"** 로 정한다.

- 「습지보전법」의 습지보호지역 **시설 종류**를 묻는다 → 법 조문을 외워야 함 → **8**
- 습지를 **어떻게 복원**하는지 묻는다 → 복원 기법 → **4**
- 습지의 **생태적 기능**을 묻는다 → 생태학 → **1**

- 생태통로의 **설치 기준·유형** → **4** (복원 설계)
- 생태통로가 왜 필요한지, 파편화와의 관계 → **2** (경관생태)

- 비오톱 **개념·유형 구분** → **2**
- 비오톱 **지도 작성 방법** → **3**
- 비오톱 지도의 **법적 활용·등급** → **8**

- 생태자연도 **등급 체계** → **8** (제도)
- 생태자연도를 만들기 위한 **조사 방법** → **3**

- 유효개체군 **계산** → **1** (개체군 생태학)
- 토량 **계산** → **5** (기반환경)

- 모니터링 **방법·항목** → **3**
- 모니터링 **결과에 따른 관리계획** → **6**

**법령이 언급됐다고 무조건 8이 아니다.** 법을 근거로 들었을 뿐 실제로는 복원
기법을 묻는 문항이 많다. 조문·수치·명칭 자체를 외워야 풀리면 8, 법은 배경일
뿐 내용이 다른 영역이면 그쪽으로 보낸다.

## 하지 말 것

- 애매하다고 특정 값(예: 1이나 8)에 몰아넣기 — 그러면 분류가 무의미해진다
- 0(미분류) 남기기 — 반드시 1~8 중 하나를 준다
