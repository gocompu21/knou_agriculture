## 정리 원칙

이 자료는 수험생이 복원한 것이라 거칠다. **읽고 다듬어서** 넣는다.

1. **문제문을 완전한 문장으로.** 원문이 "10. 깔때기효과" 처럼 제목만 있으면
   `"깔때기 효과에 대하여 설명하시오."` 로 만든다.
2. **답은 채점 포인트 단위로 나눈다.** `① 용어 : 설명` 형식.
   원문이 한 덩어리면 쪼개고, 항목이 흩어져 있으면 묶는다.
3. **문제가 요구한 개수를 맞춘다.** "3가지"인데 원문 풀이가 5개면 대표 3개만
   남기고 나머지는 `reference` 로 옮긴다.
4. **보충 설명·참고자료는 `reference` 로 분리한다.**
   원문의 `참고자료`, `※`, `용어정리` 블록이 여기 해당한다.
5. **표는 `answer_text` 에 마크다운 표로.** 이때 `answer_items` 는 빈 배열.
6. **원문 오류는 바로잡고 `notes` 에 적는다.** 이 자료에는 오타와 사실 오류가
   섞여 있다(예: r/k 선택종 분류가 뒤바뀐 사례). 사실을 확인해 옳게 쓴다.
7. **표현은 우리 문장으로.** 원문을 그대로 옮기지 말고 다듬어 쓴다.
   법조문 수치·용어 정의·분류 체계 같은 사실은 그대로 유지한다.
8. 교재 문체(~이다, ~한다)를 쓴다. 존댓말 금지.

## type 판정

| type | 기준 |
|------|------|
| 열거 | "N가지" 요구 |
| 서술 | 개념·이유·차이 설명 |
| 단답 | 용어 하나가 답 |
| 빈칸 | 괄호 채우기 |
| 계산 | 수치를 구함 |
| 표그림 | 표 완성·분류·순서 나열 |

비워 두면 적재 스크립트가 추정하지만, 되도록 채운다.

## 주의

- 원문에 `2010년 3회 기출`, `2014년 2회 기출` 같은 **이전 회차 표시**가 있다.
  이는 중복 출제 이력이므로 `notes` 에 적는다. 문제문에는 넣지 않는다.
- 답이 아예 없는 문항이 있다(원문에 `→` 뒤가 비어 있음).
  `answer_items` 를 비우지 말고, **문제문과 상식으로 답을 작성**한 뒤
  `notes` 에 "원문에 답 없음, 자체 작성"이라고 적는다.
- 그림이 필요한 문항은 `images` 를 비워 두고 `notes` 에 적는다.
  (그림은 나중에 별도로 그린다)
