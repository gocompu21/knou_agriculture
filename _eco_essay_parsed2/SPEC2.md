## 문항 객체 스키마

```json
{
  "id": "E-2019-1-01",
  "source": "기출",
  "section": "기출",
  "year": 2019,
  "round": 1,
  "number": 1,
  "page": 1,
  "type": "열거",
  "text": "환경영향평가 생활상 평가 6개 기준을 쓰시오.",
  "answer_items": ["① 대기환경 : 기상, 대기질, 악취, 온실가스", "..."],
  "answer_text": "",
  "reference": "",
  "images": [],
  "notes": ""
}
```

### 필드 규칙

- **`text`**: 노트의 문항 제목을 **완전한 문제문으로 다듬는다.** 이 자료는
  "8. 비오톱 지도화 방법 3가지"처럼 제목만 적힌 항목이 많다.
  → `"비오톱 지도화 방법 3가지를 쓰시오."` 로 어미를 붙인다.
  원래부터 "~설명하시오/쓰시오"로 끝나면 그대로 둔다.
- **`answer_items`**: 본문에 정리된 답을 항목별로. 표 형태면 `"항목 : 내용"` 으로 합친다.
  예: `"① 대기환경 : 기상, 대기질, 악취, 온실가스"`
- **`answer_text`**: 표·계산식처럼 항목으로 쪼개기 어려우면 여기에 (마크다운 표).
- **`reference`**: 본문 중 답이 아닌 보충 설명(법조문 인용 등). 없으면 빈 문자열.
- **`images`**: 그림·개념도가 답의 일부일 때만 bbox로 플래그.
  `{"page": 5, "role": "answer", "desc": "...", "bbox": [x0,y0,x1,y1]}` (비율)
- **`notes`**: 손글씨 메모의 내용, 판독 불확실, 원문 오류 등.

### 손글씨 메모 처리 — 중요

인쇄 본문과 손글씨를 **구분**한다.

| 손글씨 종류 | 처리 |
|---|---|
| 본문에 없는 **추가 답 항목** (예: 5번 계산의 `600kg`) | `notes`에 "손글씨 메모: …" 로 기록. answer_items에는 넣지 않음 |
| 본문 내용의 **암기용 축약** (예: 목록을 짧게 다시 적음) | 무시 |
| 형광펜·동그라미·밑줄 | 무시 (강조 표시일 뿐) |
| 본문을 **정정**하는 메모 | `notes`에 기록하고 answer는 본문대로 |

### type 판정

| type | 기준 |
|------|------|
| 열거 | "N가지" 요구, 항목 나열이 답 |
| 서술 | 개념·이유·차이를 문장으로 설명 |
| 단답 | 용어·명칭 하나가 답 |
| 빈칸 | 괄호/빈칸 채우기 |
| 계산 | 수치를 구함 |
| 표그림 | 표 완성·그림·순서 나열 |

## 판독 원칙

1. **답을 지어내지 않는다.** 본문에 답이 없으면 `answer_items: []`, notes에 기록.
2. 인쇄 본문의 오탈자는 그대로 두고 notes에 적는다.
3. 흐리거나 겹쳐서 못 읽는 글자는 본문에 `[판독불가]`로 표시하고 notes에 기록.
4. 페이지 넘김으로 문항이 이어지면 다음 페이지도 열어 완성한다.
5. 화학식·단위는 유니코드 첨자로 (m², CO₂, NH₄⁺).
