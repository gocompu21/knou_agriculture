# 교재 도해 → 자체 제작 SVG 지침

## 왜 하는가

문항에 붙은 그림이 교재 스캔본 그대로라 저작권 문제가 있다. **내용은
사실이므로 유지하되, 그림은 처음부터 다시 그린다.**

핵심은 "선 굵기·좌표만 바꾸는 것으로는 부족하다"는 점이다. 도형의 배치와
표현 방식(구도) 자체가 교재의 창작이므로, **시각 언어를 바꿔야 한다.**

### 실제 사례 — 2025-3 3번 (미티게이션 3단계)

| | 교재 | 자체 제작 |
|---|---|---|
| 표현 | 원 + 검은 띠 + 우상단 작은 원 (추상 도식) | 서식처 + 도로 노선 (평면 지도) |
| 회피 | 검은 반달이 원을 덮음 | 노선이 크게 우회하는 곡선 |
| 저감 | 점선 띠가 원을 가로지름 | 교각·상판이 그려진 교량 구간 |
| 대체 | 띠 관통 + 작은 원 | 서식처가 갈라지고 다른 위치에 새 서식지 |

**답 텍스트가 "노선을 바깥으로 돌린다", "교량 등으로"라고 쓰고 있어서
그 말 그대로 노선이 보이는 평면도로 바꿨다.** 이것이 이 작업의 방법이다.

## 작업 절차

1. 배치 JSON(`_figwork/fig_NN.json`)을 Read로 읽는다.
2. 각 문항의 `images[].path` 를 **Read 도구로 열어 원본 그림을 본다.**
3. `answer_items` / `answer_text` 를 읽고 **그림이 전달해야 할 사실**을 파악한다.
4. **답 텍스트를 근거로** 다른 시각 언어의 SVG를 만든다.
5. `c:\...\knou_agriculture\_figures\<이름>.svg` 로 Write.
6. 배치 JSON의 해당 문항에 `svg_name`(확장자 제외)과 `done: true` 를 기록하고
   **문항 2~3개마다 Write로 중간 저장**한다.

## SVG 작성 규칙

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 900 340"
     width="900" height="340" font-family="'Malgun Gothic','맑은 고딕',sans-serif">
  <title>…</title><desc>…</desc>
  …
</svg>
```

- **viewBox 폭 900 고정.** 높이는 내용에 맞춰 260~520 사이에서 정한다.
- 폰트는 반드시 `'Malgun Gothic','맑은 고딕',sans-serif`. 한글이 깨지지 않는다.
- **흑백 인쇄를 고려한다.** 색만으로 구분하지 말고 패턴·선종류·굵기를 함께 쓴다.
  시험지로 인쇄되는 그림이다.
- 글자 크기: 제목 20px / 라벨 15px / 설명 15.5px 안팎. 너무 작으면 인쇄에서 뭉갠다.
- 텍스트가 도형을 가리지 않게 한다. 좁으면 라벨을 도형 밖으로 빼고 지시선을 쓴다.
- 색은 이 프로젝트의 녹색 계열을 쓴다: `#1b4332`(진한), `#4f7259`(중간),
  `#f2f5f1`(옅은 배경). 강조가 필요하면 `#a1651a`(주황) 정도.

## 구도를 바꾸는 방법

원본이 이런 식이면 이렇게 바꾼다:

| 원본 유형 | 바꾸는 방향 |
|---|---|
| 동심원(핵심-완충-전이) | 평면 지도에 구역을 배치하거나, 가로 단면으로 층을 표현 |
| 순환 화살표 도식 | 세로 흐름도, 또는 단계별 카드 배열 |
| 좌우 대비 그림 두 개 | 하나의 장면에 전후를 겹쳐 표현하거나 표로 |
| 그래프(곡선) | 축·눈금·주석 위치를 다르게, 곡선 형태는 사실이므로 유지 |
| 사진·삽화 | 도식화. 사진을 흉내 내지 말고 개념도로 |
| 단면도 | 시점을 바꾼다(단면→평면, 또는 반대) |

**단, 사실을 왜곡하면 안 된다.** 예를 들어 토양 층위(O-A-E-B-C)의 순서나
생태자연도 등급 체계는 정해진 것이므로 순서·명칭을 바꾸지 않는다.
바꾸는 것은 **그것을 어떻게 보여주는가**이다.

## 그림이 필요 없는 경우

원본이 **표를 캡처한 것**이면 SVG를 만들지 말고, 배치 JSON에
`"to_table": true` 를 기록한다. 나중에 마크다운 표로 답에 넣고 이미지를
지운다. (표의 수치·항목은 사실이라 저작권 문제가 없다)

원본이 **의미 없는 장식**(교재 로고, 사진)이면 `"to_delete": true` 를 기록한다.
